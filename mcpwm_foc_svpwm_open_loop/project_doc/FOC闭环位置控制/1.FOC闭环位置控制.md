# 一、先记住：FOC 位置控制 = **3个环嵌套**
**最外层 = 位置环 → 中间层 = 速度环 → 最内层 = 电流环（FOC核心）**

```
你想转到 90°
  ↓
位置PID计算 → 输出目标转速
  ↓
速度PID计算 → 输出目标电流（扭矩）
  ↓
FOC（电流环） → 控制电机发力
```

你要做的，就是把这 **3 层串起来**。

# 二、超清晰完整流程（照着写代码）
## 1. 读取位置（AS5600）
- 读 AS5600 原始角度
- 转成 **机械角度（0~360°）**
- 转成 **电角度（给FOC用）**
- 机械角度也作为 **位置环反馈**

## 2. 位置环（PID）
**目标：让电机转到你指定的角度**
输入：
- 目标角度（你设定的，比如 45°）
- 当前角度（AS5600 读的）

计算：
```
位置误差 = 目标角度 - 当前角度
位置输出 = 误差 * KP
```

位置输出 = **目标转速**
（给下一层速度环用）

## 3. 速度环（PID）
**目标：让电机按位置环要求的转速跑**
输入：
- 目标转速（来自位置环）
- 当前转速（根据角度变化算出来）

计算：
```
速度误差 = 目标转速 - 当前转速
速度输出 = PID(速度误差)
```

速度输出 = **目标电流 Iq**
（给FOC用）

## 4. FOC 电流环（最内层）
**目标：强制电机输出对应扭矩**
输入：
- Iq 目标电流（速度环给的）
- Id = 0
- 电角度（AS5600）

FOC 做 3 件事：
1. Clarke 变换
2. Park 变换
3. PID + 反Park + SVPWM

最终输出 3 相 PWM → 电机转到目标位置

# 三、最核心公式（直接复制进代码）
## 1. 读角度
```cpp
float now_angle = getMechanicAngle(); // AS5600 机械角度 0~360
float elec_angle = now_angle * POLE_PAIRS + offset; // 电角度
```

## 2. 位置环（P控制即可，云台够用）
```cpp
float target_angle = 90.0f; // 你想转到的角度
float err = target_angle - now_angle;

// 角度误差超过 360 要处理一圈问题
if(err > 180) err -= 360;
if(err < -180) err += 360;

float target_speed = err * KP_POS; // KP=3~8
```

## 3. 速度计算
```cpp
static float last_angle = 0;
float now_speed = (now_angle - last_angle) / dt;
last_angle = now_angle;
```

## 4. 速度环（PI）
```cpp
float speed_err = target_speed - now_speed;
float Iq = KP_VEL * speed_err + KI_VEL * integral;
```

## 5. 送入 FOC
```cpp
FOC_SetCurrent(Id=0, Iq, elec_angle);
```

# FOC 位置环 KP 值怎么调？
我用**最简单、最实用、不绕弯**的方式告诉你，你马上就能调好！

---

# 一、先搞懂：位置环 KP 到底管什么？
**位置环 KP = 电机“听话程度”**
- KP 太小 → 电机**反应慢、跟不上、飘**
- KP 太大 → 电机**抖、震、啸叫**
- KP 刚好 → **指哪打哪、稳、不抖**

位置环公式：
```
PWM出力 = (目标角度 - 当前角度) × KP
```

---

# 二、最简单的调参方法（工程师标准流程）
## 步骤 1：先把 **KD = 0，KI = 0**
只留 **KP**，从零开始慢慢加！

## 步骤 2：KP 从很小开始往上加
比如从 **0.1 → 0.5 → 1 → 2 → 3 → 5 → 10**

## 步骤 3：观察电机状态
1. **KP 太小**
   电机转得慢、到位慢、轻轻一碰就歪
   
2. **KP 刚好（最佳点）**
   电机指哪打哪，快速到位，**不抖、不震、不叫**

3. **KP 太大（临界值）**
   电机开始**嗡嗡响、轻微抖动、高频尖叫**
   
   → **一旦出现抖动，马上往回减 20%~30%**
   这就是你最终的 KP！
