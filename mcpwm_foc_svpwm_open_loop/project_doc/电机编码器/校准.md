# 一句话讲透：AS5600 + FOC 为什么必须校准？
**必须校准！不校准电机要么不转、要么抖动、要么发热、根本没法用！**

我用**最简单、最通俗**的方式给你讲明白，不用任何专业术语也能听懂👇

---

# 一、核心问题：
AS5600 是个**磁铁角度传感器**，
但它**不知道你电机的线圈在哪**！

- AS5600 只管读：磁铁转了多少度（0~4095）
- FOC 算法必须知道：**电机线圈当前需要的电角度**

但你把磁铁粘在电机轴上时，**位置是随机的**！
AS5600 显示 0° 的时候，电机线圈根本不是 0°！

这中间差的那个**固定角度差**，就是你要**校准**的东西！

---

# 二、用比喻秒懂
你开车：
- 方向盘正中间 = 车直行
- 但你的方向盘**装歪了 15°**
- 你必须**把这 15° 补偿回来**，车才能走直线

FOC 也一样：
- AS5600 是方向盘
- 电机线圈是车轮方向
- 它们**天生对不齐**
- 所以必须**加一个固定偏移量 = 校准**

---

# 三、不校准会发生什么？（非常真实）
- 电机**嗡嗡响**
- 电机**发热严重**
- 电机**转不动**
- 电机**乱抖**
- 电机**反转/无力**
- FOC 完全失效

因为 FOC 给的电流方向永远是**错的**！

---

# 四、校准到底在做什么？
**只做一件事：
找到 AS5600 角度 和 电机电角度 之间的固定差值，存起来，每次都加上。**

公式变成：
```
电角度 = 机械角度 × 极对数 + 校准偏移量
```

这个 **偏移量（offset）** 就是校准出来的。

---

# 五、最简单的手动校准方法（10 秒搞定）
我给你一个**不用任何工具、不用代码**的超级简单方法：

## 步骤 1：
给电机通电解锁，用手**轻轻转动电机**
找到一个**阻力最大、力气最强、最卡的位置**
→ 这就是**正确电角度 0° 位置**

## 步骤 2：
在这个位置，读取 AS5600 输出的原始角度
例如读到：**1234**

## 步骤 3：
计算偏移：
```
偏移量 = -1234 × 极对数 × 360.0 / 4096
```

## 步骤 4：
代码里每次都加上这个偏移量即可！

// ====================== 你只需要改这里 ======================
#define POLE_PAIRS    7      // 电机极对数 12N14P=7 / 12N10P=5
#define ZERO_OFFSET   0.0f   // 自动校准后会生成正确值
// ==========================================================

// AS5600 地址
#define AS5600_ADDR 0x36

// 全局变量
float zero_offset = ZERO_OFFSET;

// 校准按键（GPIO0，ESP32 自带 BOOT 键）
#define CALIB_KEY_PIN 0

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("ESP32 + AS5600 FOC 自动校准");
  
  Wire.begin(); // I2C 默认引脚：ESP32 D21=SDA, D22=SCL

  pinMode(CALIB_KEY_PIN, INPUT_PULLUP);
  
  // 开机显示当前偏移
  Serial.print("当前偏移: ");
  Serial.println(zero_offset);
  Serial.println("按 BOOT 键开始自动校准");
}

// 读取 AS5600 原始角度 0~4095
uint16_t as5600_getRaw() {
  Wire.beginTransmission(AS5600_ADDR);
  Wire.write(0x0C);
  Wire.endTransmission();
  Wire.requestFrom(AS5600_ADDR, 2);
  
  uint8_t h = Wire.read();
  uint8_t l = Wire.read();
  
  return (h << 8) | l;
}

// 获取机械角度 0~360
float getMechAngle() {
  uint16_t raw = as5600_getRaw();
  return raw * 360.0f / 4096.0f;
}

// 获取 FOC 电角度（核心！校准后直接用这个！）
float getElectAngle() {
  float elec = getMechAngle() * POLE_PAIRS + zero_offset;
  elec = fmodf(elec, 360.0f);
  if(elec < 0) elec += 360.0f;
  return elec;
}

// 电机输出 0 电流（仅用于校准）
void motorRelease() {

  // 这里你要把电机PWM全部设为低电平
  // 让电机处于自由转动状态
  // ======================
}

// 电机输出一个小电流，锁定到最强力矩位置
void motorAlign() {
  // ======================
  // 这里你要输出一个小电流
  // 让电机自动转到最强位置
  // 电流给 0.5A ~ 1A 即可
  // ======================

// 自动校准
void autoCalibrate() {
  Serial.println("\n===== 开始自动校准 =====");
  
  // 1. 电机自由状态
  motorRelease();
  delay(200);
  
  // 2. 电机对齐到 0° 电角度
  motorAlign();
  
  // 3. 读取当前 AS5600 角度
  float mech = getMechAngle();
  Serial.print("当前机械角度: "); Serial.println(mech);
  
  // 4. 计算偏移（核心公式）
  zero_offset = -mech * POLE_PAIRS;
  Serial.print("校准完成！偏移量 = "); Serial.println(zero_offset);
  
  // 5. 锁定电机
  motorRelease();
  
  Serial.println("===== 校准结束 =====");
  Serial.println("请把上面的偏移值填入代码 #define ZERO_OFFSET");
}

void loop() {
  // 按 BOOT 键校准
  if(digitalRead(CALIB_KEY_PIN) == LOW) {
    delay(200);
    autoCalibrate();
    while(digitalRead(CALIB_KEY_PIN) == LOW);
  }

  Serial.println(getElectAngle());
  
  delay(50);

# 怎么用？（超级简单 3 步）
## 1. 改极对数
- 12N14P → `7`
- 12N10P → `5`
- 云台电机一般是 `11` 或 `14`

## 2. 接线
- AS5600 SDA → ESP32 **21**
- AS5600 SCL → ESP32 **22**
- 供电 3.3V / 5V 都可以

## 3. 校准
1. 烧录代码
2. 打开串口监视器
3. 按一下 **ESP32 上的 BOOT 键**
4. 电机自动咔哒一下 → **校准完成！**
5. 串口会输出你的 **偏移值**
6. 把偏移值复制到代码最上面：  
   `#define ZERO_OFFSET -123.45f`
