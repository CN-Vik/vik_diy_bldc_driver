AS5600 的“零点校准”，本质就是：

> **把当前磁铁所在的原始角度 RAW ANGLE，记录成新的 0° 参考点。**

也就是说，芯片并不是改变磁铁，也不是改变电机位置，而是改变了**角度换算的参考起点**。

---

## 1. AS5600 原始角度是啥？

AS5600 是 12bit 磁编码器，一圈分成：

```c
0 ~ 4095
```

也就是：

```c
4096 个刻度 = 360°
```

大概：

```c
1 LSB = 360.0f / 4096.0f = 0.08789°
```

AS5600 内部通过霍尔传感器检测磁铁方向，然后用内部算法算出磁场角度。datasheet 里说它会测量同轴径向磁化磁铁的绝对角度，输出 12bit 角度值。

比如当前磁铁位置读出来：

```c
RAW_ANGLE = 1000
```

那角度大约是：

```c
1000 * 360 / 4096 = 87.89°
```

---

## 2. 零点校准做了啥？

假设你现在机械上把电机转到你认为的“0°位置”。

但是 AS5600 读出来不是 0，而是：

```c
RAW_ANGLE = 1000
```

那你就把这个 `1000` 写入 AS5600 的 `ZPOS` 寄存器。

这样以后芯片输出 `ANGLE` 时，会把这个位置当成新的起点。

可以简单理解成：

```c
ANGLE = RAW_ANGLE - ZPOS
```

再做一圈回绕处理：

```c
if (ANGLE < 0) {
    ANGLE += 4096;
}
```

所以：

```c
RAW_ANGLE = 1000
ZPOS      = 1000
ANGLE     = 0
```

这就是零点校准。

AS5600 的寄存器表里，`ZPOS` 是起始位置寄存器，`RAW ANGLE` 是未修改的原始角度，`ANGLE` 是输出角度寄存器。

---

## 3. RAW ANGLE 和 ANGLE 的区别

这个很关键。

### RAW ANGLE

```c
RAW_ANGLE
```

表示芯片真正测出来的磁铁原始位置。

它不管你有没有设置零点。

比如磁铁在某个物理方向，永远可能读到：

```c
RAW_ANGLE = 1000
```

### ANGLE

```c
ANGLE
```

表示经过 `ZPOS`、`MPOS`、`MANG` 等配置处理后的角度。

如果你设置了：

```c
ZPOS = 1000
```

那么当前同一个磁铁位置：

```c
RAW_ANGLE = 1000
ANGLE     ≈ 0
```

所以 FOC 里一般要注意你读的是哪个：

```c
as5600_get_angle_raw();      // 原始物理角度
as5600_get_angle_degrees();  // 可能是经过 ZPOS 处理后的角度，看驱动实现
```

---

## 4. 官方零点校准流程

I2C 方式大概就是：

```text
1. 上电
2. 把磁铁/电机转到你想定义为 0° 的位置
3. 读取 RAW ANGLE
4. 把 RAW ANGLE 写入 ZPOS
5. 等待至少 1ms
6. 再读取 ANGLE，应该接近 0°
```

datasheet 里给出的 I2C 编程流程就是：把磁铁转到 start position，读取 `RAW ANGLE`，再把这个值写入 `ZPOS`，并等待至少 1ms。

---

## 5. 你的 `as5600_set_zero_position(as5600)` 大概率做的事

这个函数大概率内部就是：

```c
raw = read RAW_ANGLE;
write raw to ZPOS;
delay;
```

伪代码类似：

```c
esp_err_t as5600_set_zero_position(as5600_handle_t sensor)
{
    uint16_t raw;

    as5600_get_angle_raw(sensor, &raw);

    as5600_write_zpos(sensor, raw);

    vTaskDelay(pdMS_TO_TICKS(1));

    return ESP_OK;
}
```

也就是把当前位置设为零点。

## 6. 对 FOC 来说，零点不是随便校准的

FOC 里你真正关心的是：

```text
电角度 θe
```

不是单纯机械角度。

关系是：

```c
theta_e = pole_pairs * theta_m + offset;
```

AS5600 零点校准只是把机械角度的 0 点改了。

但 FOC 还需要知道：

```text
转子磁场 d 轴方向在哪里
```

所以 FOC 里的零点通常不是“你随便把电机转到一个位置按一下校准”就完了，而是要做**电角度零点对齐**。

常见做法：

```text
1. 给电机定子施加固定方向电流
2. 让转子吸到一个固定电角度方向
3. 读取此时 AS5600 的角度
4. 这个角度作为 FOC offset
5. 后续每次读取 AS5600 角度后减去 offset
```

所以对 FOC 更推荐软件里做：

```c
mech_angle = as5600_read_angle();
theta_e = pole_pairs * (mech_angle - zero_offset);
```

而不是频繁写 AS5600 的 ZPOS。

---

## 7. ZPOS 零点校准和软件零点校准区别

### AS5600 ZPOS 校准

优点：

```text
芯片输出的 ANGLE 本身就从 0° 开始
```

缺点：

```text
可能涉及写寄存器
如果执行 BURN_ANGLE 永久烧写，次数有限
不适合运行中频繁写
```

datasheet 里也提到，如果执行 `BURN_ANGLE` 永久写入，`ZPOS` 和 `MPOS` 的永久写入次数最多 3 次，并且需要检测到磁铁。

### 软件零点校准

优点：

```text
不改芯片寄存器
不消耗 OTP 烧写次数
适合 FOC 调试
随时可以重新校准
```

代码大概：

```c
static float zero_offset_deg = 0.0f;

void foc_zero_calibrate(void)
{
    zero_offset_deg = as5600_read_degrees();
}

float foc_get_mech_angle(void)
{
    float angle = as5600_read_degrees() - zero_offset_deg;

    if (angle < 0.0f) {
        angle += 360.0f;
    }

    return angle;
}
```

我建议你现在学习 FOC 阶段，**优先用软件零点 offset**，不要一上来就烧写 AS5600 OTP。

## 8. 最简单理解

你可以把 AS5600 想成一个圆形刻度盘。

原来芯片认为这个位置是：

```text
87.89°
```

你说：

```text
不，我现在这个位置就是 0°
```

于是你把当前 RAW 值写进 `ZPOS`。

以后芯片再看到这个位置，就输出：

```text
0°
```

这就是 AS5600 零点校准。

**有 AS5600 的电机，是“有感 FOC”；无感电机没有编码器，所以不能直接检测机械角度，只能估算角度。**

## 1. 先区分两个“零点”

### 机械零点

比如 AS5600 读出来：

```c
0° ~ 360°
```

你把当前磁铁位置定义成 0°，这个叫**机械零点**。

这个零点只是传感器角度的起点。

### 电角度零点

FOC 真正要用的是：

```c
电角度 theta_e
```

它和机械角度的关系是：

\theta_e = p \cdot \theta_m - \theta_{offset}

其中：

```text
theta_e       电角度
theta_m       AS5600 读到的机械角度
p             电机极对数
theta_offset  电角度零点偏移
```

FOC 里面最关键的是这个 `theta_offset`。

# 2. 有 AS5600 的电机，怎么做零点校准？

实际做法不是用手随便转到某个位置按一下校准，而是要**让电机自己吸到一个固定电角度位置**。

流程如下。

## 第一步：电机空载、悬空

先把电机轮子悬空，不要带负载。

参数用小一点：

```c
U_align = 1.0V ~ 3.0V
align_time = 1000ms ~ 3000ms
```

不要一上来给很大电压，不然电机会抖、发热、甚至过流。

---

## 第二步：给电机一个固定方向磁场

比如你让 FOC 输出一个固定电角度：

```c
theta_e = 0;
Ud = 2.0f;
Uq = 0.0f;
```

意思是：
**我先不让电机转，只给它一个固定方向的磁场，让转子自己吸过去。**

这时电机会“咔”一下转到某个固定位置，然后停住。

这个位置就是你定义出来的“电角度 0°附近”。

---

## 第三步：读取 AS5600 当前机械角度

电机吸住后，读 AS5600：

```c
float mech_angle = as5600_read_degrees();
```

比如读到：

```c
mech_angle = 123.4°
```

假设电机是 7 对极：

```c
pole_pairs = 7
```

那么当前机械角度对应的电角度是：

```c
elec_angle = 123.4 * 7 = 863.8°
```

归一化到 0~360：

```c
863.8 - 720 = 143.8°
```

这说明：
当你强制输出 `theta_e = 0°` 时，AS5600 对应的机械角度算出来是 `143.8°` 电角度。

所以这个 `143.8°` 就是你的 offset。

---

## 第四步：保存 offset

以后运行时就这样算：

```c
theta_e = pole_pairs * mech_angle - zero_offset;
```

再归一化到 `0 ~ 360°`。

也就是说，运行时不是直接用 AS5600 的角度，而是：

```c
AS5600机械角度
    ↓
乘以极对数
    ↓
减去电角度偏移
    ↓
得到FOC使用的电角度
```

# 3. 有感 FOC 零点校准伪代码

```c
static float g_elec_zero_offset_deg = 0.0f;
static const float POLE_PAIRS = 7.0f;

static float normalize_0_360(float angle)
{
    while (angle >= 360.0f) {
        angle -= 360.0f;
    }

    while (angle < 0.0f) {
        angle += 360.0f;
    }

    return angle;
}
```

校准函数：

```c
void foc_encoder_zero_calibrate(void)
{
    float mech_deg;
    float elec_deg;

    /*
     * 1. 给固定电角度磁场。
     * theta_e = 0°
     * Ud = 2V
     * Uq = 0V
     *
     * 这里的 foc_set_voltage_dq() 是伪函数，
     * 你要换成你自己的 FOC 电压输出函数。
     */
    foc_set_voltage_dq(2.0f, 0.0f, 0.0f);

    /*
     * 2. 等待转子吸附稳定。
     */
    vTaskDelay(pdMS_TO_TICKS(1500));

    /*
     * 3. 读取 AS5600 当前机械角度。
     */
    mech_deg = as5600_read_degrees();

    /*
     * 4. 机械角度转换成电角度。
     */
    elec_deg = normalize_0_360(mech_deg * POLE_PAIRS);

    /*
     * 5. 因为刚才我们强制输出的目标电角度是 0°，
     * 所以当前读到的 elec_deg 就是 offset。
     */
    g_elec_zero_offset_deg = elec_deg;

    /*
     * 6. 停止输出，避免电机一直发热。
     */
    foc_set_voltage_dq(0.0f, 0.0f, 0.0f);

    printf("mech=%.2f deg, elec_offset=%.2f deg\n",
           mech_deg, g_elec_zero_offset_deg);
}
```

运行时获取电角度：

```c
float foc_get_electrical_angle(void)
{
    float mech_deg;
    float elec_deg;

    mech_deg = as5600_read_degrees();

    elec_deg = mech_deg * POLE_PAIRS;

    elec_deg = elec_deg - g_elec_zero_offset_deg;

    elec_deg = normalize_0_360(elec_deg);

    return elec_deg;
}
```

如果发现电机反方向跑、抖得很厉害，可以试试方向取反：

```c
elec_deg = -mech_deg * POLE_PAIRS - g_elec_zero_offset_deg;
```

或者：

```c
elec_deg = g_elec_zero_offset_deg - mech_deg * POLE_PAIRS;
```

因为 AS5600 安装方向、电机三相顺序、FOC 坐标方向可能不一致。

# 4. 那 AS5600 自己的 ZPOS 要不要设置？

学习 FOC 阶段，我建议你先不要频繁写 AS5600 的 ZPOS。

更推荐这样：

```text
AS5600 保持原始读数
FOC 软件里保存 zero_offset
```

原因是：

```text
1. 软件 offset 更灵活
2. 不怕写错芯片寄存器
3. 调试时可以反复校准
4. 后面可以把 offset 存到 NVS/Flash
```

所以你现在可以先做：

```c
g_elec_zero_offset_deg = 校准出来的值;
```

后面稳定了，再考虑保存到 Flash。

# 5. 无感电机怎么零点校准？

严格说：

**无感电机没有编码器，所以没有“机械角度零点校准”这个概念。**

因为它没有 AS5600、霍尔、编码器这些传感器，根本不知道当前机械角度是多少。

无感 FOC 的角度一般来自估算：

```text
反电动势 BEMF
滑模观测器 SMO
PLL 观测器
磁链观测器
高频注入 HFI
```

但是普通反电动势无感有一个大问题：

```text
电机静止时没有反电动势
所以静止时很难知道转子角度
```

所以无感电机启动一般这样做。

---

## 无感启动流程 1：强制对齐 + 开环拖动 + 闭环切换

这是最常见的新手方案。

```text
1. 给固定电角度磁场，让转子吸到某个位置
2. 保持几百毫秒到几秒
3. 开环慢慢旋转电角度，把电机拖起来
4. 转速上来后，反电动势变明显
5. 启动无感观测器
6. 切换到闭环 FOC
```

也就是：

```text
静止阶段：不知道角度，强行摆正
低速阶段：开环拖动
中高速阶段：靠反电动势估算角度
```

---

## 无感启动伪流程

```c
void sensorless_startup(void)
{
    /*
     * 1. 固定电角度对齐。
     * 让转子吸到 theta_e = 0° 附近。
     */
    foc_set_voltage_dq(2.0f, 0.0f, 0.0f);
    vTaskDelay(pdMS_TO_TICKS(1000));

    /*
     * 2. 开环加速。
     * 这里不依赖传感器，自己给 theta_e 慢慢增加。
     */
    for (float speed = 0.0f; speed < STARTUP_TARGET_SPEED; speed += SPEED_STEP) {
        open_loop_theta += speed * dt;

        foc_set_voltage_dq(0.0f, startup_uq, open_loop_theta);

        vTaskDelay(pdMS_TO_TICKS(1));
    }

    /*
     * 3. 转速起来后，启动无感观测器。
     */
    sensorless_observer_enable();

    /*
     * 4. 观测器稳定后，切换到闭环。
     */
    foc_sensorless_closed_loop_enable();
}
```

注意：
这里的 `open_loop_theta` 是你软件强行生成的电角度，不是真实检测出来的角度。

# 6. 无感电机怎么检测机械角度？

普通无感 FOC：

```text
不能直接检测机械角度
只能估算电角度
```

如果你有估算电角度：

```c
theta_e_est
```

机械角度可以大概反推：

```c
theta_m_est = theta_e_est / pole_pairs;
```

但是这里有个问题：

```text
电角度每转一圈，只对应机械角度的 1 / 极对数 圈
```

比如 7 对极电机：

```text
机械转一圈 = 电角度转 7 圈
```

所以只靠电角度估算，不能唯一知道完整机械绝对位置。

举例：

```text
机械角度 0°
机械角度 51.43°
机械角度 102.86°
机械角度 154.29°
...
```

它们对应的电角度可能都是同一个相位。

所以无感更适合：

```text
速度控制
力矩控制
风扇/水泵/航模电机
```

不适合：

```text
上电就要知道绝对位置
低速大扭矩
位置伺服
平衡车低速稳定控制
机械臂位置控制
```

这些最好用编码器、霍尔、磁编码器。

# 7. 对你的学习路线建议

你现在用 AS5600 学 FOC，建议按这个顺序：

```text
第一步：AS5600 能稳定读角度
第二步：手转电机，确认角度 0~360 连续变化
第三步：确认电机极对数
第四步：做电角度零点校准
第五步：用 AS5600 角度做有感开环/闭环 FOC
第六步：再研究无感启动和观测器
```

你现在最应该先做的不是无感，而是：

```text
AS5600 + 有感 FOC
```

因为这个能让你看清楚：

```text
机械角度
电角度
极对数
零点 offset
Park / 逆 Park
SVPWM
```

这些搞明白了，再做无感会容易很多。

# 8. 最简单总结

有 AS5600：

```text
固定电角度输出
    ↓
转子吸到固定位置
    ↓
读取 AS5600 机械角度
    ↓
机械角度 × 极对数
    ↓
得到电角度 offset
    ↓
以后运行时减掉 offset
```

无感电机：

```text
静止时不知道机械角度
    ↓
先强制对齐
    ↓
开环拖动转起来
    ↓
有反电动势后估算电角度
    ↓
切到无感闭环
```

一句话：

**有感是“读角度再校准”；无感是“先强行拖起来，再估算角度”。**
