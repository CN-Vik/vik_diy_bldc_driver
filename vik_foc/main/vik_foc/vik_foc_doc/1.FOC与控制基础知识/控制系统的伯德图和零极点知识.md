哈哈，你现在正好到了这个阶段。

**以前学《自动控制原理》时觉得零极点、伯德图特别抽象，真正开始做FOC以后，你会发现它们其实就是在回答两个问题：**

> **① 我的系统稳不稳定？**
>
> **② 我的PI到底该调多大？**

这两个东西和你现在调FOC关系非常大。

---

# 一、先说最容易理解的——伯德图（Bode Plot）

其实伯德图就是：

> **系统对不同频率信号的反应。**

例如，你现在电流环：

```text
Iq_ref
   │
   ▼
 PI
   │
   ▼
 Uq
   │
   ▼
 电机
   │
   ▼
 Iq
```

如果：

```text
Iq_ref
```

不是固定0.2A，而是：

```text
0.2A

↓

0.25A

↓

0.15A

↓

0.22A

↓

……
```

一直变化。

那么：

电流环还能不能跟上？

---

例如：

变化很慢：

```text
每1秒变化一次
```

你的电流环：

```text
100%

跟得上
```

---

如果：

```text
每100ms变化一次
```

还能：

```text
95%

跟得上
```

---

如果：

```text
每10ms变化一次
```

可能：

```text
70%

跟得上
```

---

如果：

```text
每1ms变化一次
```

电流环：

```text
完全跟不上
```

---

于是画出来：

```text
响应能力

100%  ──────────╮
                │
                │
                │
                │
20%             ╰──────────────

        频率越来越高 →
```

这就是：

> **幅频特性。**

伯德图的一半。

---

## 为什么会这样？

因为：

电机有：

```text
电感L
```

电感最怕：

```text
快速变化
```

所以：

频率越高，

电流越跟不上。

---

# 伯德图还有第二部分：

叫：

> **相频特性。**

什么意思？

例如：

目标：

```text
Iq_ref

~~~~~~
```

是个正弦波。

理想：

```text
Iq_actual

~~~~~~
```

完全重合。

---

实际上：

由于：

电流建立需要时间。

于是：

```text
Iq_ref

~~~~~~
```

实际：

```text
Iq_actual

  ~~~~~~
```

慢了一点。

这叫：

> **相位滞后。**

如果：

越来越慢：

```text
~~~~~~

     ~~~~~~
```

说明：

相位越来越大。

---

所以：

伯德图实际上就是两张图：

```text
① 增益

② 相位
```

随频率变化。

---

# 那零极点又是什么？

这是很多人最怕的。

其实一句话：

> **极点决定系统性格。**

例如：

一个系统：

```text
      1
-----------
0.01s+1
```

这里：

```text
0.01s+1
```

有一个：

```text
极点
```

算出来：

```text
s=-100
```

什么意思？

就是：

系统响应速度。

例如：

```text
Uq

↓

Iq
```

需要：

```text
10ms
```

稳定。

---

如果：

变成：

```text
1
---------
0.001s+1
```

极点：

```text
-1000
```

说明：

系统：

快了10倍。

---

所以：

**极点决定：**

* 响应快慢
* 是否振荡
* 是否稳定

---

# 为什么叫极点？

因为：

数学里面：

```text
          1
G(s)=------------
      s+100
```

当：

```text
s=-100
```

下面：

```text
=0
```

整个函数：

无限大。

数学叫：

> Pole（极点）

---

# 零点呢？

例如：

```text
      s+20
-------------
      s+100
```

这里：

```text
s=-20
```

上面：

等于：

```text
0
```

所以：

叫：

> Zero（零点）

---

零点主要作用：

改变响应。

例如：

没有零点：

```text
慢悠悠
```

有零点：

```text
更快
```

但是：

超调可能增加。

---

# PI为什么会有零点？

你的PI：

```text
Kp

+

Ki/s
```

整理：

```text
Kps+Ki
---------
s
```

看看：

上面：

```text
Kps+Ki
```

是不是：

有一个：

```text
零点
```

所以：

> **PI控制器本身就在给系统增加一个零点。**

这也是：

为什么：

PI可以：

提高响应。

---

# 为什么调PI老说看伯德图？

因为：

工业上：

根本没人一个一个试。

而是：

画：

```text
开环伯德图
```

然后：

看：

```text
相位裕度

Phase Margin
```

如果：

```text
60°
```

说明：

很好。

---

如果：

```text
30°
```

危险。

---

如果：

```text
0°
```

马上振荡。

---

所以：

工业控制工程师：

很多时候：

不是看：

```text
Iq
```

而是：

看：

```text
伯德图
```

然后：

直接知道：

```text
Kp还能加多少。
```

---

# 和你现在的FOC有什么关系？

你的电流环实际上就是：

```text
         PI
          │
          ▼
      电机(RL)
          │
          ▼
         Iq
```

其中：

电机（R+L）本身就是一个**一阶系统**：

```text
          1
G(s)=------------
      Ls+R
```

它只有**一个极点**：

```text
s=-R/L
```

而你的PI控制器：

```text
Kp+Ki/s
```

会引入：

* 一个**积分极点**（在原点 `s=0`）；
* 一个**零点**（位置由 `Ki/Kp` 决定）。

所以，整个FOC电流环实际上就是：

> **"一个一阶电机 + 一个PI控制器"**。

这也是工业控制里最经典、研究得最成熟的结构。

---

## 我的建议

你现在已经开始自己写FOC了，我建议我们不要再按大学教材那种方式学（先讲拉普拉斯、再讲奈奎斯特，容易忘）。

而是按照**FOC开发的顺序**来学：

1. 一阶系统（为什么电流环是一阶）✅
2. PI为什么能控制一阶系统
3. 零点、极点在PI中的实际意义
4. 伯德图怎么看带宽、相位裕度
5. 为什么电流环带宽要比速度环高5～10倍
6. 最后再回头看《自动控制原理》，你会发现那些公式几乎都能和你的FOC代码一一对应。

这样学，你会发现零极点、伯德图不再是抽象数学，而是每天都在调试中用到的工具。
