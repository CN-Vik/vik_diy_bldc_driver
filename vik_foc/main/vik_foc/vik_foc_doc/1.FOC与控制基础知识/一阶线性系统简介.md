哈哈，这个问题问得非常好。**"一阶线性系统"**是自动控制里面最重要的概念之一，理解了它，你后面调FOC、速度环、平衡车都会轻松很多。

不过，你说的：

> **输入变量和输出变量成线性关系吗？**

**只说对了一半。**

真正的一阶线性系统有两个条件：

1. **输入和输出满足线性关系。**
2. **系统具有一阶动态特性（有一个时间常数），输出不会瞬间到达目标。**

---

# 什么叫线性？

例如：

```text
输入(Uq)        输出(Iq)

1V  ----------> 0.05A

2V  ----------> 0.10A

3V  ----------> 0.15A

4V  ----------> 0.20A
```

发现：

```text
Iq = K × Uq
```

例如：

```text
K = 0.05A/V
```

那么：

```text
Uq增加2倍

↓

Iq也增加2倍
```

就是线性的。

如果：

```text
Uq

1V

↓

Iq=0.05

2V

↓

Iq=0.25

3V

↓

Iq=0.28
```

那就是非线性。

---

# 但是，这还不能叫一阶系统！

因为：

上面只是：

```text
输入

↓

输出
```

立即变化。

而真正的电机不是这样。

例如：

现在：

```text
Uq

0V
```

突然：

```text
Uq

3V
```

Iq不会：

```text
0A

↓

0.15A
```

瞬间跳过去。

而是：

```text
0

↓

0.05

↓

0.09

↓

0.12

↓

0.14

↓

0.15
```

慢慢过去。

这就是：

> **一阶动态。**

# 为什么慢？

因为：

电机绕组：

```text
      R

────Ω────

      L
```

有：

**电感L。**

电感最大的特点：

> **电流不能突变。**

所以：

你给：

```text
Uq=3V
```

电流一定：

```text
慢慢增加
```

不会：

```text
啪！

直接0.15A
```

# 数学上怎么描述？

工业控制里面：

一阶系统：

```
          K
G(s)=------------
      τs+1
```

其中：

```text
K

系统增益
```

例如：

```text
Uq增加1V

Iq增加0.05A
```

那么：

```text

```

---

另外：

```text

时间常数
```

表示：

系统响应有多快。

例如：

```text

```

表示：

大约2ms以后，

已经到了：

**63%**。

---

例如：

最终：

```text

```

那么：

2ms以后：

```text

```

不是：

```text
0.2A
```

## 最后补充一个和你项目直接相关的知识

**严格来说，你的BLDC电机并不是一个一阶系统。**

完整模型实际上是：

```text
          Uq
           │
           ▼
       电气部分(RL)
           │
           ▼
          Iq
           │
           ▼
        电磁转矩
           │
           ▼
      转子惯量(J)
           │
           ▼
          转速
```

这里有两个动态过程：

* **电流建立**（由绕组电阻、电感决定）；
* **转速变化**（由转子惯量决定）。

因此整个电机本质上更接近**二阶系统**。

**但是**，在FOC中，你把**电流环作为最内环**，它只关心：

```text
Uq → Iq
```

这一小部分，而这一部分通常可以很好地近似为一个**一阶线性系统**。这也是为什么工业FOC的电流环大多使用PI控制，而且调起来相对简单。

所以，我之前说你的系统"很像一阶线性系统"，指的是**电流环控制对象（Uq→Iq）**，而不是整个电机。后面你做到速度环时，你会发现控制对象已经变成了：

```text
Iq → 转速
```

它的动态特性又和电流环不一样了。理解这一点，对后面做速度环、位置环、甚至平衡车都会非常有帮助。
