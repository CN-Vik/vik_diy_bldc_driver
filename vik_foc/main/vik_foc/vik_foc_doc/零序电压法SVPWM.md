太敏锐了！你提到的这个完全正确，它在学术界和工程界通常被称为**零序电压注入法（Zero-Sequence Voltage Injection）**，在代码实现中常被称为 **Min-Max 法（极值法）**。

如果你觉得前面那个“判断扇区、算时间”的代数法还是有点繁琐，那么这个“零序注入法”绝对会让你惊艳。**在现代开源 FOC 库（比如著名的 SimpleFOC）中，默认使用的就是这种方法。**

它的核心思想非常暴力但绝妙：**我不去管什么六边形和扇区了，我直接生成三相正弦波，然后硬生生地给它们塞进一个“魔法偏移量”，结果就能和七段式 SVPWM 输出一模一样的波形！**

下面我为你揭开这个“纯软件方式”的魔法，并提供可以直接运行的代码。

### 1. 为什么要“注入零序电压”？

如果你直接把 FOC 算出来的目标电压转成三相正弦波（SPWM）去驱动电机，你会遇到一个致命问题：**母线电压利用率太低**。正弦波的峰值最多只能碰到母线电压的 $86.6\%$（即 $\frac{\sqrt{3}}{2}$）。

为了压榨出剩下的 $13.4\%$ 性能，前人们发现了一个物理学漏洞：
电机是个悬空的星型负载，它**根本不在乎每一相对地的绝对电压是多少，它只在乎相与相之间的“差值”（线电压）**。

也就是说：如果我给 U、V、W 三相同时加上或减去同一个电压（这叫共模电压，或者**零序电压**），它们之间的电位差不会变，电机的电流完全不受影响！

### 2. Min-Max 法的实现步骤

我们通过寻找三相电压里的最大值和最小值，来计算这个需要注入的“零序电压”。

1. **反克拉克变换 (Inverse Clarke)：** 直接把 $U_\alpha$ 和 $U_\beta$ 变成三相纯正弦波 $U_a, U_b, U_c$。
2. **找极值：** 找出这三个数里的最大值 $V_{max}$ 和最小值 $V_{min}$。
3. **计算魔法偏移量 (零序电压)：** $V_{offset} = -\frac{V_{max} + V_{min}}{2}$
4. **注入偏移量：** 把这个 $V_{offset}$ 同时加到 $U_a, U_b, U_c$ 上。

这时候，原本完美平滑的正弦波，就会因为叠加上了这个三角形的偏移量，变成一种像马鞍一样的形状，俗称**马鞍波（Saddle Wave）**。

---

### 3. ESP32 纯 C 语言极简代码 (Min-Max 法)

对比前面还要判断扇区的代码，你会发现这种写法简直优雅到了极致，连 `switch-case` 都不需要了：

```c
#include <math.h>

#define SQRT3_OVER_2  0.8660254f

// 输入的 U_alpha 和 U_beta 需提前归一化到 -0.5 ~ +0.5 之间
svpwm_compare_t svpwm_minmax_calc(float U_alpha, float U_beta) {
    svpwm_compare_t cmp_val;

    // 1. 反克拉克变换 (将直角坐标直接变回三相 120 度相差的纯正弦值)
    float Ua = U_alpha;
    float Ub = -0.5f * U_alpha + SQRT3_OVER_2 * U_beta;
    float Uc = -0.5f * U_alpha - SQRT3_OVER_2 * U_beta;

    // 2. 找到当前时刻三相中的最大值和最小值
    float Vmax = fmaxf(Ua, fmaxf(Ub, Uc));
    float Vmin = fminf(Ua, fminf(Ub, Uc));

    // 3. 核心：计算零序电压 (中点偏移量)
    float Voffset = -(Vmax + Vmin) / 2.0f;

    // 4. 注入零序电压，并加上 0.5 的基础占空比 (将 -0.5~0.5 平移到 0.0~1.0 的 ESP32 比较值)
    cmp_val.cmp_u = Ua + Voffset + 0.5f;
    cmp_val.cmp_v = Ub + Voffset + 0.5f;
    cmp_val.cmp_w = Uc + Voffset + 0.5f;

    return cmp_val;
}

```

这几行代码吐出来的 `cmp_u, cmp_v, cmp_w`，**和前面那套复杂的六边形扇区判断法（空间矢量投影法）算出来的结果是 100% 绝对相等的！** 一位小数都不差。

### 一、 核心思路：为什么要“注入”？怎么“注入”？

在理解代码之前，必须先理清这个算法的物理本质。你可以把三相逆变器想象成一个高度固定的“盒子”（高度就是母线电压 $U_{dc}$），而我们要往里面塞进一个三相正弦波（目标电压）。

1. **SPWM 的困境（利用率低）：**
如果你直接生成三相正弦波（SPWM），为了保证波形的最高点不撞到盒子的顶部，最低点不穿透盒子的底部，正弦波的振幅就被限制死了。这导致母线电压利用率只有 **86.6%**（$\frac{\sqrt{3}}{2}$）。
2. **电机物理学的漏洞：**
电机是一个星型连接的悬空负载。它**根本不在乎每一相对地的绝对电压是多少，它只在乎 U、V、W 三相之间的“电压差”（线电压）。**
*打个比方：* 假设 U=10V, V=5V，压差是 5V。如果我给它们同时加上 100V 的“零序电压”（共模电压），变成 U=110V, V=105V，对于电机来说，压差依然是 5V，电机的转矩和电流**没有任何变化**。
3. **Min-Max 的魔法（动态平移）：**
既然加上共同的电压不影响电机，那我们就可以在运行过程中，**动态地把这三相正弦波“整体向上或向下平移”**。
怎么平移最合理？我们找到当前时刻三相电压里的**最大值**和**最小值**，然后计算它们的中心点。把这个中心点强制拉平到 0（或者母线电压的一半）。
这样一来，整个波形就能在这个“盒子”里完美居中，从而允许我们把正弦波的振幅放大，直到利用率达到 **100%**。原本平滑的正弦波，因为加入了这个动态平移量，就变成了一种带两个驼峰的“马鞍波”。

### 二、 具体实现步骤（映射到 ESP32 代码）

我们将整个过程分为 4 个严格的步骤，假设我们在代码中所有的电压都已经**归一化**（即幅值范围在 $-0.5$ 到 $+0.5$ 之间，对应占空比的 $0\%$ 到 $100\%$，中间值 $0$ 对应 $50\%$ 占空比）。

#### 第一步：反克拉克变换（Inverse Clarke）

FOC 算法上游传过来的是 $U_\alpha$ 和 $U_\beta$。我们首先不管什么利用率，直接把它们转换成相位相差 120 度的三相纯正弦信号 $U_a, U_b, U_c$。

$$U_a = U_\alpha$$

$$U_b = -\frac{1}{2} U_\alpha + \frac{\sqrt{3}}{2} U_\beta$$

$$U_c = -\frac{1}{2} U_\alpha - \frac{\sqrt{3}}{2} U_\beta$$

#### 第二步：寻找极值（Min & Max）

在每一个 PWM 中断周期（例如你设置的 20kHz，每 50us 一次）里，比较当前这一瞬间 $U_a, U_b, U_c$ 这三个变量的值，找出最大值和最小值。

* $V_{max} = \max(U_a, U_b, U_c)$
* $V_{min} = \min(U_a, U_b, U_c)$

#### 第三步：计算零序偏移量（Zero-Sequence Offset）

计算这三个正弦波当前在“盒子”里的偏心程度，并求出把它们拉回正中心所需要的补偿量。

$$V_{offset} = -\frac{V_{max} + V_{min}}{2}$$

*注意这里的负号：如果整体偏高了，我们要减去这个值让它降下来；如果整体偏低了，我们要加上这个值让它升上去。*

#### 第四步：注入偏移量并生成占空比

将算出的 $V_{offset}$ **同时**加到 $U_a, U_b, U_c$ 上，完成“马鞍波”的转变。
最后，加上 $0.5$ 的基础偏移，将范围从 $[-0.5, +0.5]$ 映射到 $[0.0, 1.0]$，这就是直接喂给 ESP32 比较器的占空比比例。

* $Duty_U = U_a + V_{offset} + 0.5$
* $Duty_V = U_b + V_{offset} + 0.5$
* $Duty_W = U_c + V_{offset} + 0.5$

### 三、 工业级健壮性处理（防爆管必备）

在真正的工程实现中，你不能算出一个 Duty 就直接塞给寄存器。如果不加限制，一旦 FOC 的 PID 环输出超调，算出的占空比超出了 0.0 ~ 1.0 的范围，ESP32 的定时器就会错乱，直接导致 MOS 管炸机。

因此，你的 `svpwm_run` 函数内部必须有一道“过调制保护”的防线：

```c
// 假设这是你包含在 foc_task 里的代码片段

// 1. 限制输入范围（圆形限制，极其重要）
// U_alpha 和 U_beta 的合成矢量长度不能超过 0.5（如果以 1.0 为母线基准）
float U_out = sqrtf(U_alpha * U_alpha + U_beta * U_beta);
if (U_out > 0.5f) {
    float scale = 0.5f / U_out;
    U_alpha *= scale;
    U_beta *= scale;
}

// 2. 执行上述的 4 步 Min-Max 算法，得到 Duty_U, Duty_V, Duty_W
// ... (代码同前) ...

// 3. 最终占空比饱和钳位（防止意外溢出）
Duty_U = fmaxf(0.0f, fminf(1.0f, Duty_U));
Duty_V = fmaxf(0.0f, fminf(1.0f, Duty_V));
Duty_W = fmaxf(0.0f, fminf(1.0f, Duty_W));

// 4. 转换为 Ticks 写入寄存器
uint32_t tick_u = (uint32_t)(Duty_U * PWM_PERIOD_TICKS);
// ... 写入 MCPWM

```

这种 Min-Max 极值法不仅代码紧凑，而且完美契合你采用的中断唤醒 FOC 任务架构，CPU 耗时极低。
