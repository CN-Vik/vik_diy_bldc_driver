可以，但要分清楚两种“零点”。

## 1. AS5600 可以记住“编码器零点”

也就是你把电机停在某个机械位置，然后让 AS5600 把当前位置当成：

```text
0°
```

以后断电再上电，只要磁铁和 AS5600 没动，它读出来的这个位置仍然接近 0°。

这个叫：

```text
编码器机械零点
```

AS5600 里对应的是 ZPOS 零点寄存器。有些驱动的 `as5600_set_zero_position()` 会写 ZPOS，有些只是做软件偏移，要看你用的驱动实现。

但是注意：**AS5600 的 OTP 永久烧录次数有限，不建议调试阶段频繁烧。**

所以学习阶段更推荐：

```text
零点保存到 ESP32 的 NVS / Flash
```

而不是反复烧 AS5600 的 OTP。

---

## 2. 上电后“自动回到零点”可以实现

流程是这样的：

```text
1. 第一次校准
   把电机手动转到你想要的 0 点位置

2. 保存这个位置
   保存 AS5600 当前角度，作为 mechanical_zero

3. 以后每次上电
   读取当前 AS5600 角度

4. 位置闭环目标设为 0°
   target_angle = 0

5. 电机自动回到保存的机械零点
```

也就是说，可以实现你说的：

```text
断电后被转到任意角度
再次上电
电机自动回到之前保存的 0 点位置
```

但前提是：

```text
1. AS5600 磁铁没有打滑
2. 电机相线没有换
3. 传感器方向 DIR 没变
4. 上电后先完成 FOC 电角度零点校准
5. 位置闭环参数足够有力
```

---

## 3. 但是：AS5600 记住的零点，不等于 FOC 电角度零点

这个很重要。

AS5600 的 0 点是：

```text
机械角度零点
```

FOC 还需要：

```text
电角度零点 zero_electric_angle
```

你要保存两个东西：

```c
mechanical_zero_deg      // 你想让电机回到的位置
zero_electric_angle_rad  // FOC 用的电角度偏移
```

灯哥代码里这个：

```c
zero_electric_angle = _electricalAngle();
```

保存的是 FOC 电角度偏移，不是用户想要的机械位置 0 点。

所以你最终应该有两个校准流程：

```text
A. 电角度校准：让 FOC 知道怎么正确发力
B. 机械零点校准：让应用知道哪个位置是 0°
```

---

## 4. 推荐你不要直接烧 AS5600，先用 ESP32 NVS 保存

比如你定义：

```c
float mechanical_zero_deg = 0.0f;
float zero_electric_angle = 0.0f;
```

机械角度读取时：

```c
float raw_angle_deg = as5600_read_angle_deg();

float motor_angle_deg = raw_angle_deg - mechanical_zero_deg;
```

然后归一化到 `-180° ~ +180°`：

```c
static float normalize_angle_180(float angle)
{
    while (angle > 180.0f)
    {
        angle -= 360.0f;
    }

    while (angle < -180.0f)
    {
        angle += 360.0f;
    }

    return angle;
}
```

使用：

```c
motor_angle_deg = normalize_angle_180(raw_angle_deg - mechanical_zero_deg);
```

这样你把电机转到想要的位置，执行一次：

```c
mechanical_zero_deg = raw_angle_deg;
save_to_nvs(mechanical_zero_deg);
```

以后上电读取 NVS：

```c
load_from_nvs(&mechanical_zero_deg);
```

然后位置目标永远设为：

```c
target_angle_deg = 0.0f;
```

电机就会自动回到你保存的零点。

## 5. 上电自动回零的控制逻辑

上电后可以这样：

```c
void app_main(void)
{
    motor_encoder_init();

    vfoc_init();

    vbus_en_io_init();
    vbus_enable(true);

    m0_fd6287_mcpwm_init();

    /*
     * 读取保存的机械零点。
     */
    load_mechanical_zero_from_nvs();

    /*
     * 做 FOC 电角度校准。
     * 这个是为了让 Uq 发力方向正确。
     */
    vfoc_align_sensor();

    /*
     * 启动位置闭环。
     * target = 0°，电机自动回到保存的机械零点。
     */
    m0_fd6287_foc_start();
}
```

控制任务里：

```c
raw_angle_deg = as5600_read_angle_deg();

current_angle_deg = normalize_angle_180(raw_angle_deg - mechanical_zero_deg);

target_angle_deg = 0.0f;

err = angle_error_deg(target_angle_deg, current_angle_deg);

uq = POS_KP * err;
uq = limit_float(uq, -UQ_LIMIT, UQ_LIMIT);

vfoc_set_svpwm(uq, 0.0f, MOTOR_DRV_VBUS);
```

## 结论

**可以实现。**

但我建议你这样做：

```text
不要优先烧 AS5600 的永久零点
先把零点保存到 ESP32 的 NVS
```

因为这样安全、可重复修改、调试方便。

你的目标功能完整说法是：

```text
保存一个机械零点 mechanical_zero_deg。
上电后读取 AS5600 当前角度。
计算当前位置相对零点的角度误差。
位置闭环控制 Uq，让电机回到 0°。
```

一句话：**AS5600 负责告诉你现在在哪，ESP32 负责记住哪里是零点，FOC 位置闭环负责把电机拉回零点。**
