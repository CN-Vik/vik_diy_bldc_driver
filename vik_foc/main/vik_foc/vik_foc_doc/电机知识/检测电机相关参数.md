在 FOC（Field-Oriented Control）里，这几个参数：

* 定子相电阻 (R_s)
* d/q 轴电感 (L_d, L_q)
* 永磁体磁链 (\psi_f)

都是**电机模型参数**，可以通过“实验测量 + 辨识”得到。下面按工程上常用方法讲清楚怎么测。

---

# 一、定子相电阻 (R_s) 怎么测

## 方法1：直流电阻法（最常用）

适用于三相对称 BLDC/PMSM。

### 步骤：

1. 电机断电、静止
2. 用万用表测两相之间电阻，例如：

   * 测 (R_{ab}), (R_{bc}), (R_{ca})

### 星形连接（常见）：

[
R_{phase} = \frac{R_{line}}{2}
]

也就是：
[
R_s = \frac{R_{ab}}{2}
]

⚠️注意：

* 电阻很小（毫欧级），普通万用表误差大
* 建议用 **四线法（Kelvin测量）**

---

## 方法2：通电压降法（更准）

1. 两相通直流电流 (I)
2. 测电压 (V)
   [
   R = \frac{V}{I}
   ]

优点：可以抵消接触电阻误差

---

# 二、d/q 轴电感 (L_d, L_q) 怎么测

这个是 FOC 里最难测的。

---

## 方法1：锁轴 + 小信号法（最标准）

### 思路：

把转子“固定在某个角度”，然后在 d 或 q 轴注入小电压/电流。

---

### 步骤：

#### 1. 锁住转子（关键）

* 用电流控制让转子停在某个角度
* 或机械固定（实验台）

---

#### 2. 测 (L_d)

* 让电流方向对准 d 轴（Id 注入）
* 注入小 AC 或阶跃电压
* 测电流响应：

[
L_d = \frac{V_d - R i_d}{di_d/dt}
]

更常见做法：

* 注入方波电压
* 记录电流上升斜率

---

#### 3. 测 (L_q)

同理：

* 在 q 轴方向注入电流（Iq）
* 测动态响应

---

## 方法2：阻抗法（LCR 或频响）

### 做法：

* 用交流信号扫频（几 Hz ~ 几 kHz）
* 测阻抗：
  [
  Z = R + j\omega L
  ]

然后：
[
L = \frac{\text{Im}(Z)}{\omega}
]

优点：

* 比较专业
* 精度高

缺点：

* 需要设备（功率放大 + 频响分析仪）

---

## 方法3：FOC在线辨识（工程常用）

在控制器中：

* 注入高频电压扰动
* 用电流响应估算 (L_d, L_q)

优点：

* 不用拆电机
* 可以在线更新

---

# 三、永磁体磁链 (\psi_f) 怎么测

这个参数对 PMSM 最关键。

---

## 方法1：反电动势法（最常用）

### 条件：

电机空载运行（或拖动）

### 步骤：

1. 让电机转速为已知 (\omega)
2. 测相电压（反电动势）

在稳态：
[
E = \omega \psi_f
]

所以：
[
\psi_f = \frac{E}{\omega}
]

---

### 实际工程做法：

* 用示波器测相电压 RMS
* 或用控制器采样

---

⚠️注意：
要减掉电阻压降：
[
E = V - iR
]

---

## 方法2：FOC稳态法（更精确）

在 dq 坐标下：

[
V_q = R i_q + \omega L_d i_d + \omega \psi_f
]

如果：

* 设 (i_d = 0)

则：
[
\psi_f = \frac{V_q - R i_q}{\omega}
]

---

## 方法3：拖动测试（最准确）

用已知扭矩负载拖动：

* 测转速 + 电压 + 电流
* 做参数拟合

工业电机厂常用

---


👉 这是“两相串联等效法”

* 电压 V
* 电流 I

### Step 3：计算线电阻：

[
R_{line} = \frac{V}{I}
]

### Step 4：换算相电阻（星形连接）：

[
R_s = \frac{R_{line}}{2}
]

## ⚠️ 常见坑

❌ 用普通万用表直接测 → 错很大
❌ 电流太小（<0.1A）→ 接触电阻占比太大
❌ 电流太大 → 温升导致电阻变大

## 条件：

让电流沿 d 轴


采样：

* Id(t)
* Ud(t)

---

## 计算方法：

电机方程：

[
U_d = R i_d + L_d \frac{di_d}{dt}

所以：

[
L_d = \frac{U_d - R i_d}{di_d/dt}
]

用上升时间：

如果电流从 0 → I，时间 t：

[
L_d ≈ \frac{U}{\Delta i / \Delta t}
]

---

## ⭐ 推荐做法（最稳）

取 10% → 90% 上升时间：

[
L_d = \frac{U_{step} \cdot t_r}{0.8 I}
]

[
\omega = \frac{2\pi n}{60}

---

### Step 5：计算磁链：

[
\psi_f = \frac{E}{\omega}
]


### Step 3：采样电流（ADC DMA）

采样：

* Ia
* Ib

然后 Clarke：

```c
Ialpha = Ia;
Ibeta  = (Ia + 2*Ib)/sqrt(3);
```

Park：

```c
Id = Ialpha*cosθ + Ibeta*sinθ;
```

---

### Step 4：求平均值（很关键）

```c
Rs = mean(Vd_buffer) / mean(Id_buffer);
```

## ⚠️ ESP32坑

* ADC必须滤波（至少32点平均）
* 不然 Rs 会抖 ±30%

# 🧪 四、Ld / Lq 测量（ESP-IDF标准方法）

> 👉 小信号 AC 注入 + DFT

## 1️⃣ Step 1：锁转子

```c
θe = 0
Id = 1A
Iq = 0
```

## 2️⃣ Step 2：注入 400Hz 正弦

```c
Vd = V0 + V1*sin(ωt)
Vq = 0
```

ESP-IDF timer 10kHz loop：


## 3️⃣ Step 3：采样 Id/Iq


## 4️⃣ Step 4：算阻抗

[
Z_d = \frac{V_d}{I_d}
]

[
L_d = \frac{\Im(Z_d)}{\omega}
]

---

同理：

[
L_q = \frac{\Im(Z_q)}{\omega}
]

## ⭐ ESP32简化版（强烈推荐你先用）

不用DFT，直接用斜率：

```c
L = (V - R*i) / (di/dt)
```

---

### 实现：

```c
float di = Id_now - Id_prev;
float dt = 0.0001f;

Ld = (Vd - Rs * Id) * dt / di;
```

## ⚠️ Ld/Lq ESP32常见坑

* PWM频率太低（<15kHz）→ 数据全乱
* 电流环没调好 → L估计发散
* 转子没锁 → Ld/Lq混在一起

# 🧪 五、永磁体磁链 ψf（ESP-IDF最稳定方法）

* Vq
