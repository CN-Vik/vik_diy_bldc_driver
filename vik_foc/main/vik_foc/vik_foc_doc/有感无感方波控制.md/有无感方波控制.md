# 4. 六步换向原理

BLDC一个电周期：

360°电角。

分：

```
60°
60°
60°
60°
60°
60°
```

每个区间：

两个绕组通电：

一个悬空。

例如：

| 步骤 | U  | V  | W  |
| -- | -- | -- | -- |
| 1  | +  | -  | 浮空 |
| 2  | +  | 浮空 | -  |
| 3  | 浮空 | +  | -  |
| 4  | -  | +  | 浮空 |
| 5  | -  | 浮空 | +  |
| 6  | 浮空 | -  | +  |

重点：

**悬空相就是用来测BEMF的。**

因为：

通电相：

```
电压=PWM+反电势+压降
```

无法测。

悬空相：

```
电压≈反电势
```

这个也是六步无感的核心。

# 5. BEMF过零检测

假设：

当前：

```

W悬空
```

```

```

但是直接看：

```

```

不行。

因为母线变化。

所以比较：

$$
Vw-\frac{Vbus}{2}
$$

例如：

参考：

```

```

```

低


W=6.2V

高
```

过零：

```
W=6V
```

就是：

BEMF zero crossing。

很多工程直接用：

$$
V_{bemf}=V_{phase}-V_{bus}/2
$$

判断。

> 不管你磁场细节，只要知道转子在哪个 60°电角度区间，就给对应三相通电。

```

    v
判断60°区间
    |
    v
查换向表
    |
    v
PWM输出
```

没有：

* Clarke
* Park
* Id/Iq
* SVPWM
* 电流环
