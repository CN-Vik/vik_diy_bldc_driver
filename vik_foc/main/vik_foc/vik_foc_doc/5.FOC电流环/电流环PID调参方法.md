这是 **FOC 最难调的部分之一**。不过，好消息是：**电流环 PI 的调试是有一套成熟的方法的**，不像很多人一开始那样靠"瞎试"。

---

# 先说明一个原则

**调电流环的时候，不要调速度环，不要调位置环。**

先保证：

```
Iq_ref  ---> PI ---> Vq
```

只有这一层。

例如：

```c
Id_ref = 0.0f;
Iq_ref = 0.5f;   // 固定给0.5A
```

观察：

```
Iq
```

是否能稳定跟踪。

---

# 第一步：Ki = 0

很多人一开始：

```
Kp = ?
Ki = ?
```

一起调。

**这是错误的。**

正确的是：

```
Ki = 0
```

只调 Kp。

例如：

```c
Kp = 0.05
Ki = 0
```

# 如果是 ESP32（10 kHz）

你的控制周期：

```
100 us
```

建议 PI 更新为：

```c
err = ref - feedback;

integral += Ki * err * Ts;

/* Anti-Windup */
integral = CLAMP(integral, -I_LIMIT, I_LIMIT);

output = Kp * err + integral;

/* 输出限幅 */
output = CLAMP(output, -V_LIMIT, V_LIMIT);
```

这里 `Ts` 为 0.0001 s（10 kHz）。

---

# 更推荐的方法：按电机参数计算初值

如果你已经知道电机的**相电阻 R** 和 **相电感 L**（或者能测出来），就不用完全靠试。可以根据电流环带宽计算一个比较合理的 `Kp`、`Ki` 初值，再做少量微调。

例如采用连续域 PI：

$$
K_p = L \cdot \omega_c
$$

$$
K_i = R \cdot \omega_c
$$

其中 (\omega_c = 2\pi f_c)，`f_c` 是你希望的电流环带宽，一般可取 PWM 频率的约 1/10 到 1/20。对于 **10 kHz PWM**，很多系统会先尝试 **500～1000 Hz** 左右的电流环带宽，然后根据实际响应调整。

---

**结合你的项目（ESP32 + 10 kHz PWM + 平衡车 FOC）**，我建议不要一开始完全靠经验调参。如果你告诉我：

1. 电机相电阻 **R**（Ω）
2. 电机相电感 **L**（μH 或 mH）
3. 母线电压（例如 24 V、36 V、48 V）

我可以直接帮你算出一组适合作为起点的 **Kp、Ki**，通常第一次上电就能得到比较接近理想的电流环响应。
