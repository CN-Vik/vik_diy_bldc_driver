# 一、ωe（电角速度）到底用“度还是弧度”？

## ✅ 结论（非常重要）：

> 👉 **必须统一用“弧度制”**

---

## 为什么？

你的解耦公式是：

```c
Ud = Ud_pid + ωe * Lq * Iq;
Uq = Uq_pid - ωe * Ld * Id;
```

这里的 ωe 本质是：

> **电角速度 = dθe/dt**

---

### ⚠️ 如果你用“度/s”会怎样？

* sin/cos 是弧度
* 电机方程推导是弧度体系
* L·di/dt 是 SI 单位体系

👉 只要你 ω 用“度/s”，就会出现：

* 解耦量错 57.3 倍（π/180）
* 电机直接抖 / 啸叫 / 电流爆炸

---

## ✅ 正确统一方式：

### 电角度：

```c
theta_e (rad)
```

### 电角速度：

```c
omega_e = d(theta_e)/dt  // rad/s
```

---

## ⚠️ 你代码里现在的坑：

你有这个：

```c
get_vfoc_theta_e_rad(...)
```

但你其实返回的是“rad”，又做了一次处理。

👉 你必须确保：

| 变量      | 单位    |
| ------- | ----- |
| theta_e | rad   |
| ωe      | rad/s |
