于是电机转到一个稳定位置：

```text
机械角 = 278.44°
```

这说明：

> **当电角度 = 0° 时，转子的机械角是 278.44°。**

因此可以保存：

```c
electrical_offset_mech = 278.44f;
```

注意，它保存的是**机械角**。

---

## 以后计算电角度

你的电机是 **7 对极**，所以以后应该计算：

```c
theta_e_deg = (theta_mech_deg - electrical_offset_mech) * 7.0f;
```

例如：

### 当前机械角

```text
278.44°
```

计算：

```text
theta_e = (278.44 - 278.44) × 7 = 0°
```

完全正确。

---

### 转了 1°

机械角：

```text
279.44°
```

计算：

```text
theta_e = (279.44 - 278.44) × 7
        = 7°
```

也正确。

---

### 转了半圈（180°机械角）

```text
theta_e = 180 × 7 = 1260°
```

然后取模：

```text
1260 % 360 = 180°
```

也符合 7 对极电机的规律。

---

## 所以千万不要这样保存

有的人会写：

```c
electrical_offset = 278.44 * 7;
```

这是**不建议的**。

因为以后你每次都要：

```c
theta_e = theta_mech * 7 - electrical_offset;
```

虽然数学上等价，但精度和可读性都不如直接保存机械角偏移。

---

## 不过，我建议你再验证一次

虽然 **278.44° 很有可能就是正确的 offset**，但最好再做一个验证。

恢复正常电角度计算：

```c
theta_e = (theta_mech - 278.44f) * 7;
```

然后：

```c
Uq = 2.0f;
Ud = 0.0f;
```

观察 Park 变换后的电流：

* 理想情况：

  ```text
  Iq ≈ 正值（例如 0.3A）
  Id ≈ 0A
  ```

如果变成：

```text
Iq ≈ 0
Id ≈ 0.3A
```

或者：

```text
Iq ≈ -0.3A
```

说明还存在 **90° 或 180° 的相位偏差**，需要再调整 offset。

### 我还有一个问题想确认一下

你这个 Alignment 是固定：

```c
theta_e = 0
Ud = 2.0f
```

**等待电机完全停住以后**读取的 `278.44°`，还是**刚开始转动时**就读取的？

这个区别很重要。**只有电机完全稳定、不再转动以后读到的机械角，才能作为最终的 `electrical_offset_mech`。**
