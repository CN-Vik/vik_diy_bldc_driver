你这个 `vfoc_curent_loop()` 里的 LOG 要改，**但还有一个更大的 BUG 要先改：你现在 `vfoc_curent_loop()` 被调用了两次。**

你现在是：

```c
vfoc_set_svpwm(
    vfoc_curent_loop().Uq,
    vfoc_curent_loop().Ud,
    MOTOR_DRV_VBUS
);
```

这会导致：

```text
第一次调用：算一次电流环，返回 Uq
第二次调用：又算一次电流环，返回 Ud
```

这两个值不是同一次采样、同一次 Park、同一次 PID 算出来的，而且你的 `vfoc_pid_calute()` 里面还有 static 状态，调用两次会把 PID 状态搞乱。你上传的代码里就是这个写法。

---

## 1. 先把 `m0_foc_control_task()` 改掉

改成只调用一次：

```c
static void m0_foc_control_task(void *arg)
{
    pwm_duty_t pwm_duty;

    while (1)
    {
        ulTaskNotifyTake(pdTRUE, portMAX_DELAY);

        /*
         * 只调用一次电流环。
         * 不能写 vfoc_curent_loop().Uq / vfoc_curent_loop().Ud，
         * 那样会执行两次电流环。
         */
        park_parm_t vdq_cmd = vfoc_curent_loop();

        vfoc_set_svpwm(
            vdq_cmd.Uq,
            vdq_cmd.Ud,
            MOTOR_DRV_VBUS
        );

        pwm_duty = vfoc_get_pwm_duty();

        m0_fd6287_set_duty(
            pwm_duty.duty_Ua,
            pwm_duty.duty_Ub,
            pwm_duty.duty_Uc
        );
    }
}
```

这个必须先改。

## 2. `vfoc_curent_loop()` 里的 LOG 建议改成这样

你现在 LOG 太少，只打印：

```text
uq, id, iq, ia, ib, ic, theta
```

但你调电流环时真正要看的是：

```text
Uq指令
Ud指令
Iq目标
Iq实际
Iq误差
Id目标
Id实际
Id误差
三相电流
电角度
平均电流
```

把你原来的 `if ((cnt++)>100)` 里面替换成下面这个：

```c
    /*
     * 统计平均绝对值，避免只看某一个瞬时点。
     * 因为 ia/ib/ic/iq 是交流量，单点日志可能刚好采到过零点。
     */
    static uint32_t log_cnt = 0;

    static float ia_abs_sum = 0.0f;
    static float ib_abs_sum = 0.0f;
    static float ic_abs_sum = 0.0f;
    static float id_abs_sum = 0.0f;
    static float iq_abs_sum = 0.0f;

    ia_abs_sum += fabsf(motor_ia);
    ib_abs_sum += fabsf(motor_ib);
    ic_abs_sum += fabsf(motor_ic);
    id_abs_sum += fabsf(now_id);
    iq_abs_sum += fabsf(now_iq);

    log_cnt++;

    if (log_cnt >= 100)
    {
        float ia_abs_avg = ia_abs_sum / (float)log_cnt;
        float ib_abs_avg = ib_abs_sum / (float)log_cnt;
        float ic_abs_avg = ic_abs_sum / (float)log_cnt;
        float id_abs_avg = id_abs_sum / (float)log_cnt;
        float iq_abs_avg = iq_abs_sum / (float)log_cnt;

        float iq_err = exp_iq - now_iq;
        float id_err = exp_id - now_id;

        ESP_LOGI(
            TAG,
            "cur_loop: "
            "uq_cmd=%.3fV, ud_cmd=%.3fV, "
            "uq_pid=%.3fV, ud_pid=%.3fV, "
            "iq_ref=%.3fA, iq_now=%.3fA, iq_err=%.3fA, "
            "id_ref=%.3fA, id_now=%.3fA, id_err=%.3fA, "
            "ia=%.3fA, ib=%.3fA, ic=%.3fA, "
            "iq_abs_avg=%.3fA, id_abs_avg=%.3fA, "
            "ia_abs_avg=%.3fA, ib_abs_avg=%.3fA, ic_abs_avg=%.3fA, "
            "theta=%.3frad",
            uq_cmd,
            pid_out_ud,
            pid_out_uq,
            pid_out_ud,
            exp_iq,
            now_iq,
            iq_err,
            exp_id,
            now_id,
            id_err,
            motor_ia,
            motor_ib,
            motor_ic,
            iq_abs_avg,
            id_abs_avg,
            ia_abs_avg,
            ib_abs_avg,
            ic_abs_avg,
            theta_e_temp
        );

        log_cnt = 0;
        ia_abs_sum = 0.0f;
        ib_abs_sum = 0.0f;
        ic_abs_sum = 0.0f;
        id_abs_sum = 0.0f;
        iq_abs_sum = 0.0f;
    }
```

## 3. 但是你现在 `uq_cmd = 3.5` 是固定测试，LOG 要标清楚

你当前代码里：

```c
float uq_cmd = 3.5;
l_temp_park_v.Uq = uq_cmd;
l_temp_park_v.Ud = pid_out_ud;
```

也就是说：

```text
Uq 不是 PID 输出
Uq 是你手动固定的 3.5V
```

所以你看 LOG 时要注意：

```text
uq_cmd=3.500V：实际输出给 SVPWM 的 Uq
uq_pid=xxxV：PID 算出来的 Uq，但当前没用
```

如果你要做纯固定 Uq 测试，我建议先把 Ud 也固定成 0：

```c
l_temp_park_v.Uq = uq_cmd;
l_temp_park_v.Ud = 0.0f;
```

不要一边固定 `Uq=3.5`，一边又让 `Ud` 用 PID。否则你不好判断。

## 4. 更建议你把返回结构体名字改掉

你现在用 `park_parm_t` 同时表示：

```text
Park 反馈电流：Id/Iq
输出电压指令：Ud/Uq
```

这会越看越乱。

建议新增一个结构体：

```c
typedef struct
{
    float Ud;   /* d轴电压指令，单位 V */
    float Uq;   /* q轴电压指令，单位 V */
} vdq_cmd_t;
```

然后：

```c
vdq_cmd_t vfoc_curent_loop(void)
```

这样更清楚。

## 5. 还有一个隐藏大坑：Iq PID 和 Id PID 不能共用 `vfoc_pid_calute()`

你现在：

```c
float pid_out_uq = vfoc_pid_calute(... iq ...);
float pid_out_ud = vfoc_pid_calute(... id ...);
```

但是 `vfoc_pid_calute()` 里面有：

```c
static int64_t last_stamp_time_us = 0;
static float last_err = 0.0f;
static float ki_err_sum = 0.0f;
```

所以 **Iq 环和 Id 环共用了同一套 PID 状态**。这会乱。

短期测试固定 Uq 时可以先这样：

```c
float pid_out_ud = 0.0f;
```

先别开 Id PID。

后面标准做法是：

```text
Iq PID 一个 ctx
Id PID 一个 ctx
```

不能共用 static。

## 6. 你现在最小可用版改法

先这样最简单，方便你继续测堵转和电角度 offset：

```c
/*输出uq限幅*/
pid_out_uq = limit_float(pid_out_uq, -UQ_LIMIT, +UQ_LIMIT);

/*
 * 当前先做固定 Uq 测试。
 * 注意：这里没有用 pid_out_uq。
 */
float uq_cmd = 3.5f;
float ud_cmd = 0.0f;

l_temp_park_v.Uq = uq_cmd;
l_temp_park_v.Ud = ud_cmd;
```

LOG 里就看：

```text
uq_cmd
ud_cmd
id_now
iq_now
id_abs_avg
iq_abs_avg
ia_abs_avg / ib_abs_avg / ic_abs_avg
theta
```

这样最清楚。

一句话：**先把 `vfoc_curent_loop()` 只调用一次，然后 LOG 分清楚“输出电压指令 Uq/Ud”和“反馈电流 Iq/Id”。现在你的 LOG 最大问题是字段含义不够清楚，而且控制任务里电流环被调用了两次。**
