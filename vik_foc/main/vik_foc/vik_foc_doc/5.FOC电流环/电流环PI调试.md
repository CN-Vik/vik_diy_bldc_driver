# 我给你举一个最容易理解的例子

假设你的2208电机是个自行车。

**Uq就是你踩踏板的力量。**

**Iq就是链条上的拉力（力矩）。**

## 第一种情况：自行车在空中

轮子悬空。

你轻轻踩一下：

```
轮子：

疯狂加速

一直越来越快
```

但是链条上的拉力呢？

```
几乎没有
```

为什么？

因为：

```
没有阻力。
```

所以：

**你的力不是用来"产生拉力"。**

而是：

```
全部拿去加速了。
```

所以：

```
Iq≈0
```

---

## 第二种情况：轮子压在地上

你再踩。

现在车子要推动人。

于是：

```
有阻力
```

这时候：

```
链条开始有拉力
```

于是：

```
Iq开始变大。
```

---

## 第三种情况：轮子堵住

你死命踩。

轮子不动。

所有力都变成：

```
链条拉力
```

于是：

```
Iq最大。
```

所以你实验看到：

```
堵转

Uq↑

Iq↑
```

这是完全正确的。

# 为什么空载Iq只有0.03A？

因为你的2208电机很轻。

例如：

```
Uq=3V
```

它可能马上转到：

```
1000RPM
```

这时候：

电机自己产生反电动势。

反电动势越来越大。

最后：

```
Uq≈反电动势
```

于是：

真正流进绕组里的电流：

```
几乎没有。
```

所以：

```
Iq≈0
```

这是正常的。

# 那工业上怎么调Iq？

工业根本不会让电机空载去调Iq。

```

```

这就是调电流环。

---

## 方法2

低速。

例如：

```
20RPM
```

不是：

```
1000RPM
```

因为：

速度低。

反电动势小。

Iq比较容易建立。

---

## 方法3

给负载。

例如：

```
风扇

减速箱

皮带

飞轮
```

只要有负载。

Iq自然会上来。
