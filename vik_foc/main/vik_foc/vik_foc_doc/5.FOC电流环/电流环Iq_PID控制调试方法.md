# 二、电流环对象本质（非常关键）

dq轴电流模型：

```text id="m1"
Vq = R * Iq + L * dIq/dt + ωe * ψf
```

你现在**缺少 ωe·ψf 补偿**，意味着：

> PI 必须“自己扛反电动势”

👉 等价于：系统变“更难控制 + 更慢 + 更容易积分饱和”

# 三、你的 dt 决定了 Kp/Ki 的量级

电流环离散 PI：

```text id="m2"
Uq = Kp * e + Ki * ∫e dt
```
