## 1. FOC里面力矩公式是什么？

BLDC/PMSM：

FOC里面：

$$
T_e = K_t I_q
$$

也就是：

> 电机输出力矩 = 转矩常数 × q轴电流

其中：

* (T_e)：电磁转矩 Nm
* (K_t)：转矩常数 Nm/A
* (I_q)：q轴电流

> **电流环控制的是电机产生的电磁力矩，而不是直接控制速度。**

# 1. BLDC/PMSM力矩来源

电机产生力矩，本质：

**定子磁场和转子永磁磁场相互作用。**

FOC做了一件事情：

把三相电流：

```
Ia
Ib
Ic
```

转换成：

```
Id
Iq
```

其中：

* Id：励磁方向（产生磁链）
* Iq：转矩方向（产生力矩）

对于表贴式永磁同步电机（你的2208基本属于SPMSM）：

$$
T_e=\frac{3}{2}p\psi_f I_q
$$

这个就是FOC最重要公式。

所以：

高速时候：


* 解耦补偿
* 弱磁控制
* 电压限制
