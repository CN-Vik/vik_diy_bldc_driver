+
L_q\frac{di_q}{dt}

> **低速 Iq 环正常，高速 Iq 环开始崩。**

# 13. 所以高速的时候需要解耦/反电动势补偿

对于 PMSM：

$$
u_d=R_si_d+L_d\frac{di_d}{dt}-\omega_eL_qi_q
$$

$$
u_q=R_si_q+L_q\frac{di_q}{dt}
+\omega_e(L_di_d+\psi_f)

所以可以加入：

```c

Uq_decouple =  omega_e * (Ld * Id + psi_f);
```

最终：

```c
Ud = Ud_PI + Ud_decouple;
Uq = Uq_PI + Uq_decouple;
```

如果：

```text
Id = 0
```

那么：

$$
U_q^{decouple}\approx\omega_e\psi_f
$$

也就是主要补偿反电动势。

# 1. PMSM/BLDC 的 FOC 转矩公式

对于 PMSM，在 dq 坐标系下，电磁转矩公式是：

$$
\boxed{
T_e=
\frac{3}{2}p
\left[
\psi_f I_q+
(L_d-L_q)I_dI_q
\right]
}
$$

其中：

| 参数       | 含义       |
| -------- | -------- |
| (T_e)    | 电磁转矩，N·m |
| (p)      | 极对数      |
| ($$\psi_f$$) | 永磁体磁链，Wb |
| (I_d)    | d轴电流，A   |
| (I_q)    | q轴电流，A   |
| (L_d)    | d轴电感，H   |
| (L_q)    | q轴电感，H   |

你这个 **2208-80T，12槽14极**：

$$
\boxed{p=7}
$$

# 8. 还有一个特别重要的单位问题

很多人这里会算错。

机械角速度：

$$
\omega_m
$$

电角速度：

$$
\omega_e=p\omega_m
$$

而力矩公式里的 (p) 已经包含极对数。

不要把：

```text
机械转速 RPM
```

直接塞到转矩公式里。

转矩计算**不需要转速**：

$$
\boxed{
T_e=\frac32p\psi_fI_q
}
$$

所以理论上：

> **同一个 (I_q)，低速和高速产生的电磁转矩基本由这个公式决定。**

高速时的问题主要变成：

> **你有没有足够的母线电压维持这个 (I_q)。**

这就是为什么你之前遇到的：

> 电机低速 Iq 好控制，高速以后 Iq 控制变差。

本质上是**电压裕量不够 + 反电动势上升**，不是转矩公式变了。

---

# 9. 如果你的电机不是表贴式，就不能这么简单

如果是 IPMSM：

$$
L_d\neq L_q
$$

那么：

$$
T_e=
\frac32p
[
\psi_fI_q+(L_d-L_q)I_dI_q
]
$$

这时候：

$$
I_q=\frac{T_e}{\frac32p\psi_f}
$$

就不再完全准确。

因为 (I_d) 也参与产生：

> **磁阻转矩 Reluctance Torque**

于是会涉及：

* MTPA
* 弱磁
* ($I_d/I_q$) 最优分配

但你这个 2208 普通表贴式 BLDC，**第一版完全可以按照 (I_d=0) 的模型做。**

---

# 10. 最终你程序里可以这么设计

例如：

```c
typedef struct
{
    float torque_ref;    // 期望电磁转矩 Nm
    float iq_ref;        // 期望Iq A

    float pole_pairs;    // 极对数
    float flux_linkage;  // 永磁磁链 Wb
    float kt;             // 转矩常数 Nm/A

} torque_ctrl_t;
```

初始化：

```c
torque->pole_pairs   = 7.0f;
torque->flux_linkage = 0.0079f;

torque->kt =
    1.5f *
    torque->pole_pairs *
    torque->flux_linkage;
```

得到：

```text
Kt ≈ 0.083 Nm/A
```

然后：

```c
torque->iq_ref =
    torque->torque_ref /
    torque->kt;
```

再限流：

```c
if (torque->iq_ref > IQ_MAX)
    torque->iq_ref = IQ_MAX;

if (torque->iq_ref < -IQ_MAX)
    torque->iq_ref = -IQ_MAX;
```

最后：

```c
Iq_PI(torque->iq_ref, Iq);
```

## 你现在可以把整个 FOC 控制链记成一句话

$$
\boxed{
T^*
\rightarrow
I_q^*
\rightarrow
I_q\ PI
\rightarrow
U_q
\rightarrow
SVPWM
\rightarrow
电机转矩
}
$$

对于你这个 **7极对、(\psi_f≈0.0079Wb)** 的 2208：

$$
\boxed{
T_e\approx0.083I_q
}
$$

所以：

$$
\boxed{
I_q^*\approx12.05T_e^*
}
$$

这就是你要做“**给定 N·m 力矩指令的 FOC**”时最核心的一层。
