完全理解！控制理论里确实充斥着各种黑话和抽象符号，新手一上来看到一堆 $\omega$、$J$、$T$ 确实容易抓狂。

其实这些参数之所以存在，是因为**算法需要知道电机的“电学体重”和“机械体重”**，才能给出轻重正好的力道。

### 重新回头看那些公式，是不是变简单了？

现在我们把这些大白话带进你之前懵逼的公式里：

1. **电流环 $K_p = L_s \cdot \omega_c$**
* **大白话：** 电流环的放大倍数（$K_p$） = 电机的电学阻力（$L_s$） $\times$ 你期望的电流环反应速度（$\omega_c$）。电学阻力越大，或者你想让它反应越快，你的 $K_p$ 就要调得越大。


2. **位置环 PD 里的 $K_{pd} = \frac{2 \omega_p}{\omega_v} - 1$**
* **大白话：** 微分项 $K_d$ 的本质是**阻尼（刹车）**。这个公式的意思是，你希望外环（位置环）指令给得越快（$\omega_p$ 越大），你就必须提供越大的阻尼系数（$K_{pd}$）去拉住电机，否则电机就会因为惯性冲过头。



控制理论的魅力就在于，它把电机摸得透透的，只要你把电机的“电学体重”（$L_s$）、“机械体重”（$J$）和“力气”（$K_t$）输入进去，算法就能自动吐出最完美的 PID 参数。

在ESP32上实现FOC（磁场定向控制）是一个极具挑战但也非常有成就感的项目。针对你的问题，首先要明确一点：**在FOC的电流环（$I_q$ 和 $I_d$）中，我们通常只使用 PI（比例-积分）控制，而不使用 D（微分）**。因为电流采样信号通常包含大量高频噪声（尤其是ESP32内置ADC的噪声相对较大），加入微分项会放大这些噪声，导致系统崩溃。

以下是关于如何调节PI参数以及如何用C语言编写带限幅（Anti-windup）的PI控制器的详细指南。

---

### 一、 FOC电流环 PI 参数怎么调？

电流环的参数调节有两种主流方法：**公式计算法（推荐）**和**经验试凑法**。

#### 1. 公式计算法（带宽法 - 零极点对消）

如果你知道电机的**相电阻 $R_s$** 和 **相电感 $L_s$**（可以通过万用表和LCR表测量），这是最快、最稳的方法。

电流环的PI参数可以通过设定的电流环带宽（$\omega_c$）直接计算得出：

* **比例系数：** $K_p = L_s \cdot \omega_c$
* **积分系数：** $K_i = R_s \cdot \omega_c$

**如何选择带宽 $\omega_c$？**
$\omega_c$ 的单位是 $rad/s$。一般建议电流环的带宽设置为PWM开关频率的 $1/20$ 到 $1/10$。

* 假设你的PWM频率是 $20\text{ kHz}$，即 $125600\text{ rad/s}$。
* 你可以将 $\omega_c$ 设定为 $1000$ 到 $2000$。
* *举例：* 如果你的电机 $R_s = 5\Omega$，$L_s = 0.001\text{ H}$，带宽设为 $1000$，那么 $K_p = 1$，$K_i = 5000$。

#### 2. 经验试凑法（无电机参数时）

如果你无法测量电机的电感和电阻，可以按以下步骤手动整定：

1. **准备：** 确保电机空载或固定。将 $K_i$ 设为 0。设定一个方波阶跃的 $I_q$ 目标值（例如 $0 \to 0.5\text{A} \to 0$）。
2. **调 $K_p$：** 从一个极小的值（比如 $0.01$）开始，逐渐增大 $K_p$。使用串口绘图仪（如 Arduino IDE 的 Serial Plotter）观察实际电流。当电流响应变快，但**开始出现高频啸叫或震荡时**，将 $K_p$ 减小 $20\% \sim 30\%$ 作为最终值。
3. **调 $K_i$：** 保持上述 $K_p$ 不变。慢慢增大 $K_i$（由于积分项涉及时间，数值可能很大，比如几十到几百）。当电流能迅速且平滑地消除稳态误差，紧跟目标电流，且没有明显的超调（Overshoot）时，参数就调好了。

### 二、 PI 控制器应该怎么写？（核心：抗积分饱和）

你提到 $U_q$ 限制幅度为 3.5V。由于存在这个物理输出限制，你的 PI 代码中**必须包含抗积分饱和（Anti-windup）逻辑**。如果不加这个逻辑，当输出达到 3.5V 时，积分器还会继续累加错误（Windup），导致目标值下降时，电机响应极度迟缓，甚至失控。

下面是一个标准的、适用于 FOC 电流环的 PI 控制器 C 语言实现：

```c
// 定义 PI 控制器结构体
typedef struct {
    float kp;           // 比例系数
    float ki;           // 积分系数
    float integral;     // 积分累加器
    float out_max;      // 输出上限 (你的设定是 3.5)
    float out_min;      // 输出下限 (你的设定是 -3.5)
} PI_Controller;

// 初始化 PI 控制器
void PI_Init(PI_Controller *pi, float kp, float ki, float limit) {
    pi->kp = kp;
    pi->ki = ki;
    pi->integral = 0.0f;
    pi->out_max = limit;
    pi->out_min = -limit;
}

// PI 计算函数 (需在电流环定时中断中等周期调用)
// dt 为两次调用的时间间隔，例如 10kHz 控制环 dt = 0.0001f
float PI_Update(PI_Controller *pi, float setpoint, float measured, float dt) {
    // 1. 计算偏差
    float error = setpoint - measured;
    
    // 2. 积分累加 (带 dt 确保积分与执行频率解耦)
    pi->integral += pi->ki * error * dt;
    
    // 3. 积分抗饱和限幅 (Anti-windup 核心)
    // 防止积分器在电机达到物理极限时无限制增长
    if (pi->integral > pi->out_max) {
        pi->integral = pi->out_max;
    } else if (pi->integral < pi->out_min) {
        pi->integral = pi->out_min;
    }
    
    // 4. 计算最终输出 Uq
    float output = (pi->kp * error) + pi->integral;
    
    // 5. 输出限幅
    if (output > pi->out_max) {
        output = pi->out_max;
    } else if (output < pi->out_min) {
        output = pi->out_min;
    }
    
    return output;
}

```

#### 代码关键点解析：

1. **带有 `dt` 参数：** 很多网上的 PID 代码不带 `dt`，直接写 `integral += ki * error`。这种写法会导致你的 $K_i$ 参数严重依赖于代码执行的频率。加上 `dt` 后，你用公式计算出来的 $K_i$ 才能直接用进代码里。
2. **两层限幅：** 第一层是对 `integral` 限制，第二层是对最终 `output` 限制。这确保了 $U_q$ 永远被死死卡在 $\pm 3.5\text{V}$ 的范围内。

### 关于你设定的 $U_q = 3.5\text{V}$ 的一点提示：

你的母线电压 $V_{bus} = 12\text{V}$。在使用 SVPWM（空间矢量脉宽调制）时，电机相电压理论上最大可以输出到 $V_{bus} / \sqrt{3} \approx 6.92\text{V}$。
你将 $U_q$ 限制在 $3.5\text{V}$ 是非常安全的早期调试做法（留有很大余量）。但这也会导致电机无法达到它的最大转速（因为电机反电动势加上 $I_q R_s$ 不能超过 3.5V）。当你的电流环调通之后，如果你觉得转速不够，可以安全地将这个限制放宽到 $6.0\text{V}$ 左右。

简短截说：在做 **FOC 电流环** 时，强烈建议**直接写死固定值（例如 `dt = 0.0001f`），绝对不要用时间戳实时计算。**

主要原因有以下三点，这关乎到 FOC 系统的稳定性和 ESP32 的执行效率：

---

### 1. FOC 电流环必须运行在硬件中断（ISR）中

在标准的 FOC 架构中，电流环的执行流程是：**ADC 采样相电流 $\to$ Park/Clarke 变换 $\to$ PI 控制器 $\to$ SVPWM 输出**。整个过程必须与 PWM 的载波同步。

因此，电流环代码通常是挂在 **MCPWM 的定时器中断** 或 **ADC 采样完成中断** 里的。既然是硬件定时器触发，它的周期就是绝对精准的。

* 如果你的中断频率是 $10\text{ kHz}$，`dt` 理论上就是完美无瑕的 $0.0001\text{s}$。
* 如果用时间戳（如 `esp_timer_get_time()`）去实时减出差值，再转换成 `float`，不仅毫无必要，反而会在高频中断里**白白浪费 ESP32 的 CPU 算力**。

### 2. 顺便纠正一个关键点：1kHz 对电流环太慢了

你在问题中提到 “task 任务 1KHZ”，如果这是指电流环，那电机会大概率无法正常工作。

* **电流环（Current Loop）：** 负责控制电流（扭矩），响应必须极快。通常运行频率在 **$10\text{ kHz} \sim 20\text{ kHz}$**。如果只有 $1\text{ kHz}$，电机会伴随巨大的高频啸叫，且电流根本压不住，极易过流烧板子。
* **速度环/位置环（Velocity/Position Loop）：** 这两个外环不需要那么快，通常运行在 **$500\text{ Hz} \sim 1\text{ kHz}$**。如果你说的是速度环，那 $1\text{ kHz}$ 是完全没问题的。

---

### 3. 什么时候才需要用时间戳实时计算 `dt`？

只有当你的代码运行在一个非确定性（有时间抖动）的环境中时，才需要实时计算 `dt`。

* **不能写死的情况：** 你把 PID 算法写在 FreeRTOS 的普通 Task 里，并且用的是普通的 `vTaskDelay(1)`。因为 FreeRTOS 的任务调度存在微秒级的抖动，每一次循环的实际间隔可能一会儿是 $0.95\text{ms}$，一会儿是 $1.05\text{ms}$。这时候为了积分准确，必须用时间戳实时计算 `dt`。
* **可以写死的情况：** 即使在 Task 里，如果你使用的是 `vTaskDelayUntil()`（一种自动追踪绝对时间的延迟函数），或者干脆像前文说的，直接把算法挂在硬件定时器中断里。只要定时器是准的，`dt` 直接用常数定义即可。

---

在FOC（磁场定向控制）系统中，有了电流环之后，要实现完整的运动控制，就需要引入**速度环**和**位置环**。它们与电流环一起构成了经典的串级控制（Cascade Control）系统。

数据流向是：**目标位置 $\to$ 位置环计算 $\to$ 目标速度 $\to$ 速度环计算 $\to$ 目标电流（$I_q$） $\to$ 电流环计算 $\to$ 输出电压（$U_q$）**。

下面为你详细解答运行频率、代码实现以及调参步骤。

---

### 一、 位置环和速度环的 Task 运行频率

在 ESP32 中，由于这两个外环不需要像电流环（10kHz+）那么高频的响应，通常推荐的处理方式是：**创建一个独立的 FreeRTOS Task，运行频率设为 $1\text{ kHz}$（周期 $1\text{ ms}$），在同一个 Task 内先后执行位置环和速度环。**

* **速度环频率：** 推荐 $1\text{ kHz} \sim 2\text{ kHz}$。太慢会导致速度控制有抖动，太快会放大编码器微分算速度带来的噪声。
* **位置环频率：** 推荐 $500\text{ Hz} \sim 1\text{ kHz}$。因为速度是位置的微分，位置环比速度环慢一点或同步是完全没问题的。

**为什么放同一个 Task？**
因为位置环的输出直接就是速度环的输入，把它们放在同一个 $1\text{ kHz}$ 的 Task 里顺次执行，可以避免多任务调度带来的不必要延迟。

---

### 二、 代码实现（串级 PID）

为了代码的复用性，我们可以写一个通用的 PID 结构体。

#### 1. 通用 PID 结构体与函数

```c
typedef struct {
    float kp;
    float ki;
    float kd;
    float integral;
    float last_error;
    float out_max;  // 输出上限
    float out_min;  // 输出下限
} PID_Controller;

// PID初始化
void PID_Init(PID_Controller *pid, float kp, float ki, float kd, float out_limit) {
    pid->kp = kp;
    pid->ki = ki;
    pid->kd = kd;
    pid->integral = 0.0f;
    pid->last_error = 0.0f;
    pid->out_max = out_limit;
    pid->out_min = -out_limit;
}

// PID计算 (dt固定为0.001s)
float PID_Update(PID_Controller *pid, float setpoint, float measured, float dt) {
    float error = setpoint - measured;
    
    // 1. 比例项
    float p_out = pid->kp * error;
    
    // 2. 积分项 + 抗饱和
    pid->integral += pid->ki * error * dt;
    if (pid->integral > pid->out_max) pid->integral = pid->out_max;
    else if (pid->integral < pid->out_min) pid->integral = pid->out_min;
    
    // 3. 微分项 (这里用了最简单的差分，速度环如果噪声大可以加低通滤波)
    float d_out = pid->kd * (error - pid->last_error) / dt;
    pid->last_error = error;
    
    // 4. 总输出与限幅
    float output = p_out + pid->integral + d_out;
    if (output > pid->out_max) output = pid->out_max;
    else if (output < pid->out_min) output = pid->out_min;
    
    return output;
}

```

#### 2. FreeRTOS 中的 1kHz 串级控制任务

在实际应用中，我们需要用两个全局变量 `target_iq` 来和电流环（中断）进行通信。

```c
// 全局变量，用于中断和任务间通信
volatile float global_target_iq = 0.0f; 
volatile float motor_current_position = 0.0f; // 由编码器驱动实时更新
volatile float motor_current_velocity = 0.0f; // 由编码器驱动实时更新

PID_Controller pos_pid;
PID_Controller vel_pid;

void vMotionControlTask(void *pvParameters) {
    // 初始化外环PID
    // 位置环输出的是目标速度，限制电机最大转速为 50 rad/s (约470 RPM)
    PID_Init(&pos_pid, 5.0f, 0.0f, 0.0f, 50.0f); 
    
    // 速度环输出的是目标电流Iq，限制最大电流为 1.5A (根据你的电机和驱动板决定)
    PID_Init(&vel_pid, 0.1f, 0.5f, 0.0f, 1.5f);

    float target_position = 3.14159f; // 设定的目标位置（比如旋转到180度）
    const float dt = 0.001f;          // 1kHz 对应 1ms
    
    TickType_xLastWakeTime = xTaskGetTickCount();

    while (1) {
        // 使用 vTaskDelayUntil 确保绝对精准的 1ms 周期
        vTaskDelayUntil(&TickType_xLastWakeTime, pdMS_TO_TICKS(1));

        // 1. 位置环计算 -> 得到目标速度
        // 注：位置环通常只需要 P 控制（Kp），Ki和Kd设为0
        float target_velocity = PID_Update(&pos_pid, target_position, motor_current_position, dt);

        // 2. 速度环计算 -> 得到目标电流 Iq
        // 注：速度环通常使用 PI 控制（Kp, Ki），Kd通常为0
        float target_iq = PID_Update(&vel_pid, target_velocity, motor_current_velocity, dt);

        // 3. 将计算结果传给电流环 (10kHz 的中断服务函数会自动读取这个 global_target_iq)
        global_target_iq = target_iq;
    }
}

```

---

### 三、 速度环与位置环参数怎么调节？

**核心原则：由内向外调。** 必须先确保内环稳定，才能调外环。你现在电流环已经调好了，接下来的顺序是：**先调速度环 $\to$ 再调位置环**。

#### 1. 速度环整定（PI 控制）

把位置环注释掉，直接给速度环设定一个目标值（例如 `target_velocity = 10.0f;` 10 rad/s）。

1. **调 $K_p$：** 将 $K_i$ 设为 0。从小到大调节 $K_p$。用串口绘图仪观察实际速度响应。当电机转动起来，且能够跟随目标速度，但**开始出现明显的抖动或高频噪声（嗡嗡声）时**，将 $K_p$ 乘以 0.6 作为最终值。
2. **调 $K_i$：** 保持 $K_p$。开始慢慢调大 $K_i$。没有 $K_i$ 时，电机由于阻力会有静差（比如目标10，实际只能跑到8）。增加 $K_i$ 直到这个静差完全消失，速度能完美吻合目标值，且没有剧烈的速度超调。
3. *注：速度环一般不要加 $K_d$，因为编码器算出来的速度本身就有离散噪声，加 $K_d$ 会极大地放大噪声导致电机发热。*

#### 2. 位置环整定（通常纯 P 控制即可）

速度环调稳后（电机能稳定地根据指令控速），把位置环代码接通。

1. **调 $K_p$：** 位置环的 $K_i$ 和 $K_d$ 直接设为 0。设定一个位置阶跃信号（如 $0 \to 3.14 \to 0$）。
2. 从小到大调节位置环的 $K_p$。你会发现电机转过去的速度越来越快。
3. 继续增大 $K_p$，直到电机到达目标位置时**刚刚好产生了一点点超调（冲过头一点点又弹回来）**，此时将 $K_p$ 稍微减小一点点（减小 10%~20%），让它能够快速到达且不冲过头。
4. **关于 $K_i$：** 如果你的电机轴上挂了重物（比如机械臂受到重力），导致电机停下时总是差一点点对不准，这时候可以给位置环加一个**非常小的 $K_i$**。如果是普通的无重力负载，位置环**绝对不要加 $K_i$**，否则极易导致系统多轮震荡（甚至飞车）。

### 💡 调参口诀总结：

* **电流环：** 动作最快，压制瞬时过流。
* **速度环（PI）：** 动作次之，消除速度静差，负责抗负载扰动（比如拿手去阻挡电机时，速度环会立刻加大电流对抗）。
* **位置环（纯P）：** 动作最慢，负责把位置误差转化为速度指令。只要速度环底子好，位置环的 $K_p$ 可以拉得比较高，电机表现就会非常刚硬。

既然你已经通过带宽法调好了电流环，那么电机的电回路就可以被抽象为一个已知的整体。接下来，我们可以利用控制理论中的对称最佳设计法（Symmetrical Optimum）**来定量计算速度环，再利用**极点配置法（Pole Placement）来计算位置环。

要开启科学调参，你只需要提前获取以下 **3 个物理参数**：

1. $J$：系统总转动惯量（电机转子转动惯量 + 负载转动惯量，单位：$\text{kg}\cdot\text{m}^2$）
2. $K_t$：电机转矩常数（单位：$\text{N}\cdot\text{m/A}$，通常可以从电机数据手册查到）
3. $T_c$：电流环的等效时间常数。它等于你电流环带宽 $\omega_c$ 的倒数，即 $T_c = 1 / \omega_c$（例如电流环带宽是 $1000\text{ rad/s}$，则 $T_c = 0.001\text{ s}$）

---

## 一、 速度环的科学调参：对称最佳法 (Symmetrical Optimum)

由于运动学方程中，速度是力矩的积分（$\omega = \int \frac{T}{J} dt$），这意味着电机的机械对象本身就是一个**积分环节**。在控制理论中，对于含积分环节的对象，最经典、抗扰动最强的设计方法就是**对称最佳法**。

根据对称最佳法，为了让速度环拥有最佳的相角裕度（约 $53^\circ$，此时系统兼顾了快速响应与抗负载冲击能力），速度环 PI 参数的计算公式极其纯粹：

$$\begin{aligned} K_{pv} &= \frac{J}{2 \cdot K_t \cdot T_c} \\ K_{iv} &= \frac{K_{pv}}{4 \cdot T_c} = \frac{J}{8 \cdot K_t \cdot T_c^2} \end{aligned}$$

> **💡 为什么不需要 $K_d$？**
> 从公式中可以看出，对称最佳法天然只需要 $K_p$ 和 $K_i$。引入 $K_d$ 反而会破坏机械系统的低通滤波特性，放大编码器噪声。

---

## 二、 位置环的科学调参：临界阻尼极点配置法

当你的速度环按照上面的“对称最佳法”调好后，整个速度闭环在物理上就可以被近似看作一个**一阶低通滤波器**，其等效时间常数 $T_v = 4 \cdot T_c$。

位置环通常**只需要纯 P 控制（$K_{pp}$）**。为了让位置控制达到**临界阻尼状态（$\zeta = 1$）**——即保证电机以最快速度对准目标位置，且**绝对不产生任何过冲和振荡**，我们可以通过极点配置推导出 $K_{pp}$ 的几何解：

$$K_{pp} = \frac{1}{4 \cdot T_v} = \frac{1}{16 \cdot T_c} = \frac{\omega_c}{16}$$

发现了吗？最神奇的地方来了：**在严谨的数学推导下，位置环的 $K_p$ 参数居然只取决于你最初设定的电流环带宽 $\omega_c$！**

### 第一步：理解“套娃原则”（带宽分离）

FOC 的位置、速度、电流三环，就像一组俄罗斯套娃。

* **电流环（最内环）：** 动作必须最快，带宽设为 $\omega_c$。
* **速度环（中环）：** 必须比电流环慢。如果它们一样快，就会在系统里“打架”（产生共振）。通常工业标准是：速度环带宽 $\omega_v = \omega_c / 5$。
* **位置环（最外环）：** 必须比速度环更慢。通常标准是：位置环带宽 $\omega_p = \omega_v / 4$。

> **什么是带宽（$\omega$）？**
> 你可以简单把它理解为“系统的反应速度”，单位是 $rad/s$。带宽越高，电机对指令的跟随就越紧密、越刚硬。

---

### 第二步：准备电机的“物理密码”

要进行科学计算，你不需要去啃厚厚的自动化教材，只需要拿到电机的 **2 个核心物理参数**：

1. **$J$（系统转动惯量，单位：$\text{kg}\cdot\text{m}^2$）：** 象征电机的机械阻力。如果是小云台电机，通常在 $1 \times 10^{-5}$ 到 $5 \times 10^{-5}$ 之间（电机手册上一般有，或者可以用圆柱体公式粗略估算）。
2. **$K_t$（转矩常数，单位：$\text{N}\cdot\text{m/A}$）：** 象征电机的电动力。也就是给 1 安培电流，电机能产生多大的力矩。
* *给新手的硬核福利公式：* 如果你不知道 $K_t$，去查电机的 **KV值**。它们存在完美的反比关系：

$$K_t \approx \frac{9.55}{\text{KV}}$$



*(例如：一个 KV140 的轴承电机，$K_t \approx 9.55 / 140 \approx 0.068\text{ N}\cdot\text{m/A}$)*

### 第三步：套入科学调参公式（核心代码参数）

假定你已经用上一篇的方法，把电流环带宽稳定在了 $\omega_c = 1000\text{ rad/s}$。现在我们开始定量计算外两环。

#### 1. 速度环（PI控制）计算

为了让速度环既能快速追踪、又绝对不产生多余的剧烈振荡，我们引入经典控制学中表现最完美的**阻尼比 $\zeta = 0.707$（工程最佳组合）**。

速度环带宽定为：$\omega_v = 1000 / 5 = 200\text{ rad/s}$。
公式如下：


$$K_{pv} = \frac{1.414 \cdot \omega_v \cdot J}{K_t}$$

$$K_{iv} = \frac{\omega_v^2 \cdot J}{K_t}$$

#### 2. 位置环（纯P控制）计算

位置环是最好计算的。当速度环被上面的公式完美驯服后，它对位置环来说就像一个完美的“执行机构”。

位置环带宽定为：$\omega_p = 200 / 4 = 50\text{ rad/s}$。
公式极为纯粹：


$$K_{pp} = \omega_p = 50$$

### 一、 科学调参：位置环 PD 的数学推导

当你的速度环调好后，它在物理上可以等效为一个带延迟的闭环环节，其等效时间常数 $T_v = 1 / \omega_v$（$\omega_v$ 是你上一阶段设定的速度环带宽）。

我们将位置环配置为标准的**二阶控制系统**。为了让电机既能以最快速度对准目标，又**绝对不产生任何多余的晃动**，我们直接将目标阻尼比设为 **临界阻尼 $\zeta = 1.0$**。

由于引入了 D 项提供阻尼，位置环的带宽 $\omega_p$ 终于可以突破限制了！现在我们可以大胆地将位置环带宽设为：


$$\omega_p = \omega_v \times 0.75$$


*（相比纯 P 时的 $\omega_v / 4$，速度提升了整整 3 倍！）*

通过极点配置，PD 参数的终极科学计算公式如下：

$$K_{pp} = T_v \cdot \omega_p^2 = \frac{\omega_p^2}{\omega_v}$$

$$K_{pd} = 2 \cdot \zeta \cdot \omega_p \cdot T_v - 1 = \frac{2 \omega_p}{\omega_v} - 1$$

### 三、 避坑指南：PD 代码应该怎么写？

在写位置环 PD 代码时，新手极易写成 `D_out = Kd * (error - last_error) / dt`。
**注意：在位置环中绝对不要这样写！** 因为当你突变目标位置（比如目标从 0° 瞬间变成 90°）时，`error` 会发生瞬间巨变，导致微分项算出一个无穷大的冲击电流，电机不仅会发出刺耳的“咔哒”撞击声，还极易导致 ESP32 报错过流。

#### 终极解决方案：测量微分（Derivative on Measurement）

微积分原理告诉我们，位置的微分就是速度。既然你的编码器驱动已经实时算出了电机的**实际物理转速**，我们直接用实际转速作为 D 项的输入！这样既消除了指令突变带来的冲击，又天然自带了极其平滑的物理阻尼。

请在你的 $1\text{ kHz}$ 外环 Task 中这样实现 PD 运算：

```c
// 定义位置环 PD 结构体
typedef struct {
    float kp;
    float kd;
    float out_max;  // 输出限制（即允许的最大目标速度）
    float out_min;
} Pos_PD_Controller;

// 位置环 PD 计算函数
float Pos_PD_Update(Pos_PD_Controller *pd, float target_pos, float current_pos, float current_vel) {
    // 1. 计算位置偏差
    float pos_error = target_pos - current_pos;
    
    // 2. 比例项
    float p_out = pd->kp * pos_error;
    
    // 3. 微分项：直接使用电机的实际测量速度（current_vel），前面带负号表示阻尼反向
    // 注意：这里的 current_vel 单位必须是 rad/s
    float d_out = -pd->kd * current_vel;
    
    // 4. 总输出（目标速度）
    float target_velocity = p_out + d_out;
    
    // 5. 限幅
    if (target_velocity > pd->out_max) target_velocity = pd->out_max;
    else if (target_velocity < pd->out_min) target_velocity = pd->out_min;
    
    return target_velocity;
}

```

* **电机到达目标时还是有微小的尖锐震荡：** 说明你的编码器测速可能有微小的噪声并被 $K_{pd}$ 放大了。此时不需要动 $K_{pp}$，只需要把 $K_{pd}$ 稍微往大调一点（比如从 `0.5` 调到 `0.6`），增强物理阻尼即可。
* **电机启动时有一点点软：** 可以尝试将目标带宽 $\omega_p$ 再次拉高（比如设为 `160`），重新代入公式计算出一组略大的 $K_{pp}$ 和 $K_{pd}$ 填入即可。
