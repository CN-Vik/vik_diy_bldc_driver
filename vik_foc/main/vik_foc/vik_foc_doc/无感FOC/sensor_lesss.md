无感FOC的方法其实很多，你现在知道的 **SMO（滑模观测器）+ PLL** 只是其中一种，而且属于最经典、应用最广的一类：**基于反电动势（BEMF）的无感估算方法**。

无感FOC的核心目标都是一样的：

> **不用编码器/霍尔，估算转子的电角度 θe 和速度 ωe。**

不同方法只是“观察转子”的方式不同。

---

# 1. 反电动势类（BEMF Based）——你现在做的

## ① SMO + PLL（滑模观测器）

这是最经典的。

原理：

电机模型：

$$
U=RI+L\frac{dI}{dt}+E
$$

通过：

* 已知电压
* 测量电流

反推出：

$$
E_{\alpha},E_{\beta}
$$

然后：

$$
\theta_e=atan2(E_\beta,E_\alpha)
$$

结构：

```
       Ua Ub Uc
          |
          v
       Clarke
          |
          v
       αβ电压
          |
          |
电流 ----> SMO
          |
          v
   Eα Eβ(反电动势)
          |
          v
        PLL
          |
          v
       θe ωe
```

优点：

* 算法成熟
* STM32、TI、英飞凌大量使用
* 中高速效果很好

缺点：

* 低速差
* 0速失效

---

## ② Luenberger Observer（龙伯格观测器）

也是基于反电动势。

数学上：

建立状态观测器：

状态：

$$
x=[i_\alpha,i_\beta,E_\alpha,E_\beta]
$$

通过误差反馈：

```
实际电流
     |
     v
状态观测器
     |
预测电流
     |
误差修正
```

优点：

* 比SMO平滑
* 噪声小

缺点：

* 参数敏感
* 调参复杂

---

## ③ MRAS（模型参考自适应）

Model Reference Adaptive System

两个模型：

参考模型：

```
电压、电流
    |
真实模型
```

可调模型：

```
估计速度θ
    |
模型
```

比较误差：

调整：

$$
\omega
$$

直到：

两个模型一致。

优点：

* 理论漂亮
* TI早期大量使用

缺点：

* 低速一样困难

---

## ④ EKF / 卡尔曼滤波

扩展卡尔曼：

把电机状态作为：

$$
x=
[\theta,\omega,i]
$$

通过：

预测：

```
下一时刻状态
```

测量：

```
ADC电流
```

融合。

优点：

精度高。

缺点：

计算量大。

ESP32可以跑简单EKF，但20kHz FOC比较吃力。

# 2. 高频注入类（HFI）——解决0速低速

这个就是解决你刚才说的：

> 坡上停车怎么办？

原理：

给电机叠加：

高频信号：

例如：

```
Vdq

+
10kHz小电压
```

因为：

转子磁场造成：

$$
L_d \neq L_q
$$

不同方向：

电流响应不同。

检测：

```
高频电流变化

       |
       v

转子角度
```

优点：

✅ 0 rpm有效
✅ 堵转有角度

缺点：

* 需要电机有凸极性
* IPMSM效果好
* SPMSM效果差

---

# 3. 磁链观测器（Flux Observer）

不是直接观察反电动势。

估算：

定子磁链：

$$
\psi_s=\int(U-RI)dt
$$

然后：

磁链方向：

就是转子位置。

结构：

```
电压
 |
积分器
 |
磁链
 |
角度
```

优点：

低速比BEMF好一点。

缺点：

积分漂移严重。

---

# 4. 高频信号+磁链融合

工业里面常见：

不是一个算法。

例如：

```
0~500rpm

HFI


500rpm以上

SMO
```

切换：

```
          HFI
           |
0rpm -------|---------
           |
           |
        SMO+PLL

```

---

# 5. 直接反电动势过零（六步无感）

这个你可能见过：

BLDC无感六步。

检测：

悬空相：

BEMF过零。

例如：

```
U+ V-

检测W相
```

优点：

简单。

缺点：

不是FOC。

---

# 6. 高频旋转注入（Rotating HF Injection）

类似HFI，但是注入：

旋转高频电压。

用于：

高性能IPMSM。

所以你现在学习路线：

```
Clarke/Park
      ↓
PI电流环
      ↓
SVPWM
      ↓
SMO
      ↓
PLL
      ↓
开环启动切换
      ↓
HFI
```

基本就是工业无感FOC的完整路线。

你现在搞的 **ESP32 + SMO + PLL**，其实已经进入TI InstaSPIN、ST MCSDK这类商业方案的核心算法区域了。你后面真正难的不是SMO公式，而是**低速启动、PLL稳定、参数辨识和算法切换**。
