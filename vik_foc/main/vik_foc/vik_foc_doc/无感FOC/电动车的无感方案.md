你问的“电动车纯无感方案”，实际上是无感FOC里面最难的一类，因为电动车有几个苛刻条件：

* **0 rpm要有大扭矩**
* **坡道停车后还能起步**
* **低速爬坡要稳定**
* **高速效率要高**
* **不能依赖霍尔/编码器**

所以单纯的：

> SMO + PLL + 反电动势

基本不够。

电动车级纯无感FOC一般采用**低速/高速多算法融合**。

---

# 一、典型纯无感电动车架构

整体结构大概：

```
                 电机
                  |
                  |
              三相电流
                  |
                  v

        +----------------+
        | 位置估算融合器 |
        +----------------+
             ^       ^
             |       |
             |       |
        HFI估算    BEMF估算
        (低速)     (高速)

             |
             v

          电角度θe

             |
             v

          FOC控制
```

也就是：

```
0rpm -------- 低速 -------- 中高速 -------- 高速

 HFI          HFI            SMO             SMO
              +
             融合
```

# 二、0 rpm ～ 低速：高频注入 HFI

这是纯无感电动车能爬坡的关键。

因为：

反电动势：

$$
E=K_e\omega
$$

0转：

$$
E=0
$$

所以不能观察BEMF。

HFI换思路：

不看速度。

看：

**转子磁场造成的电感变化。**

---

## 1. PMSM为什么能测位置？

永磁同步电机：

d轴：

沿磁钢方向。

q轴：

垂直磁钢方向。

对于IPMSM：

```
       N
       |
       |
S -----+-----
       |
       |
```

不同方向磁阻不同：

$$
L_d \neq L_q
$$

所以：

给一个高频电压：

例如：

$$
U_h=5kHz
$$

如果方向：

```text
d轴方向

电流响应:
小
```

如果：

```text
q轴方向

电流响应:
大
```

通过电流差：

推出：

转子方向。

---

# 三、电动车为什么喜欢IPMSM？

因为：

IPMSM：

```
磁钢埋在铁芯里面
```

天然：

Ld != Lq

所以：

HFI效果好。

例如：

新能源汽车：

大量：

* IPMSM
* Interior PMSM

而普通航模BLDC：

表贴式：

```
磁钢贴外面
```

通常：

Ld≈Lq

HFI困难。

---

# 四、HFI怎么控制？

FOC里面：

正常：

```
Ud=0

Uq控制转矩
```

HFI时：

加入：

```
Ud_h = A*sin(wt)
```

例如：

5kHz。

于是：

实际：

```
Ud = PI输出 + 高频信号
```

采样电流：

然后：

提取：

高频响应。

流程：

```
PWM
 |
高频电压
 |
电机
 |
高频电流
 |
带通滤波
 |
解调
 |
角度
```

---

# 五、速度起来以后切换SMO

当：

速度达到：

比如：

300~1000rpm

BEMF足够：

切换：

HFI → SMO

---

为什么？

高速：

BEMF优势明显：

```
转速↑

BEMF↑

信噪比↑
```

SMO：

高速非常准。

---

# 六、关键：HFI和SMO怎么融合？

不是：

突然切换。

否则：

角度跳变：

电机：

```
咔！
```

甚至失步。

一般：

两个角度：

$$
\theta_{HFI}
$$

和：

$$
\theta_{SMO}
$$

做融合：

例如：

低速：

```
θ=θHFI
```

高速：

```
θ=θSMO
```

中间：

加权：

$$
\theta=
k\theta_{SMO}
+
(1-k)\theta_{HFI}
$$

其中：

k：

随速度增加。

# 七、坡道停车怎么解决？

你的问题：

> 停在坡上，速度=0怎么办？

纯无感方案：

流程：

停车：

```
speed=0
```

HFI仍然工作：

```
检测转子位置
```

得到：

```
θe
```

然后：

司机拧油门：

目标：

Iq

FOC：

输出：

```
Iq电流
```

产生：

```
保持力矩
```

车不会溜。

# 八、但是普通BLDC电动车为什么很多没有HFI？

成本。

HFI需要：

* 高采样ADC
* 高PWM频率
* 电流采样质量高
* 电机参数准确

普通电动车：

几十元控制器：

一般：

```
霍尔 + 六步
```

或者：

```
霍尔FOC
```

总结一句：

**真正的纯无感电动车FOC不是“SMO算角度”，而是：**

```
0rpm:
HFI找角度

低速:
HFI保持

中高速:
SMO/PLL接管

高速:
弱磁控制
```

这才是能做到“坡上停车还能起步”的纯无感方案。你现在研究的SMO+PLL，其实只覆盖了这个系统里的“高速半部分”。
