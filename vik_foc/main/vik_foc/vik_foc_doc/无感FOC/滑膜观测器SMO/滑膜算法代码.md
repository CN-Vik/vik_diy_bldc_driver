## 我建议你改成这个版本

这里我**保留你现在的接口、参数形式、`SMO_Sat()`、LPF 和 Eα/Eβ 的符号体系**，只把 SMO 结构改正确。

```c
/**
 * @brief 初始化滑模观测器
 */
uint8_t SMO_Init(smo_ctrl_t *smo)
{
    if (smo == NULL)
    {
        return 1;
    }

    smo->Rs = MOTOR_RS;
    smo->Ls = MOTOR_LS;
    smo->Ts = SMO_TS;

    /* 滑模增益 */
    smo->k_smo = 15.5f;

    /* 电流估计值 */
    smo->i_alpha_est = 0.0f;
    smo->i_beta_est  = 0.0f;

    /* 反电动势 */
    smo->ebmf_alpha = 0.0f;
    smo->ebmf_beta  = 0.0f;

    /* 电角度 */
    smo->theta_e = 0.0f;

    return 0;
}


/**
 * @brief 滑模饱和函数
 */
static inline float SMO_Sat(float err, float delta)
{
    if (err > delta)
        return 1.0f;

    if (err < -delta)
        return -1.0f;

    return err / delta;
}


/**
 * @brief 滑模观测器更新
 */
float SMO_Update(smo_ctrl_t *smo,
                 float u_alpha,
                 float u_beta,
                 float i_alpha,
                 float i_beta)
{
    if (smo == NULL)
    {
        return 0.0f;
    }

    /* =========================================================
     * 1. 电流估计误差
     * ========================================================= */

    float i_alpha_err =
        smo->i_alpha_est - i_alpha;

    float i_beta_err =
        smo->i_beta_est - i_beta;


    /* =========================================================
     * 2. 滑模控制量
     *
     * Z = K * sat(i_hat - i)
     *
     * 这个量既作为滑模注入项，
     * 同时参与下一步电流观测。
     * ========================================================= */

    float z_alpha =
        smo->k_smo *
        SMO_Sat(i_alpha_err, 0.5f);

    float z_beta =
        smo->k_smo *
        SMO_Sat(i_beta_err, 0.5f);


    /* =========================================================
     * 3. 更新电流观测器
     *
     * di_hat/dt =
     *
     *      -Rs/Ls * i_hat
     *      +1/Ls * (u - z)
     *
     * ========================================================= */

    smo->i_alpha_est +=
        smo->Ts *
        (
            (-smo->Rs / smo->Ls) *
            smo->i_alpha_est
            +
            (u_alpha - z_alpha) /
            smo->Ls
        );

    smo->i_beta_est +=
        smo->Ts *
        (
            (-smo->Rs / smo->Ls) *
            smo->i_beta_est
            +
            (u_beta - z_beta) /
            smo->Ls
        );


    /* =========================================================
     * 4. 对滑模注入量进行低通滤波
     *
     * Z 的平均值 ≈ 反电动势
     *
     * 注意：
     * 这里的符号是否需要取反，
     * 最终要通过实际 Eα/Eβ 旋转方向验证。
     * ========================================================= */

    smo->ebmf_alpha =
        low_pas_filter(
            0.45f,
            smo->ebmf_alpha,
            z_alpha
        );

    smo->ebmf_beta =
        low_pas_filter(
            0.45f,
            smo->ebmf_beta,
            z_beta
        );


    /* =========================================================
     * 5. 根据 Eα/Eβ 计算电角度
     *
     * 保持你原来的角度定义
     * ========================================================= */

    smo->theta_e =
        -atan2f(
            smo->ebmf_alpha,
            smo->ebmf_beta
        );


    /* =========================================================
     * 6. 角度归一化到 [0, 2π)
     * ========================================================= */

    if (smo->theta_e < 0.0f)
    {
        smo->theta_e += 2.0f * FOC_PI;
    }

    if (smo->theta_e >= 2.0f * FOC_PI)
    {
        smo->theta_e -= 2.0f * FOC_PI;
    }


    return smo->theta_e;
}
```

# 但是这里有一个非常重要的地方

我上面写的是：

$$
Z=k\operatorname{sat}(\hat i-i)
$$

然后：

$$
\hat{\dot i}
=
-\frac RL\hat i+
\frac{u-Z}{L}
$$

**这套符号必须和你的实际 SMO 数学模型一致。**

你的原代码就是：

```c
(u_alpha - ebmf_alpha_est) / Ls
```

所以我先保持了这个符号。

但是这里存在一个关键验证：

> **LPF(Z) 到底是 +E 还是 -E？**

不能靠代码注释判断。

# 你现在应该怎么验证？

这个特别简单。

让电机以一个比较稳定的速度转，比如你之前的几百 RPM。

同时记录：

```c
ebmf_alpha
ebmf_beta
```

然后看：

```text
Eα/Eβ
```

是不是一个正常旋转的圆。

比如：

```text
Eα：

    /‾\      /‾\
___/   \____/   \___


Eβ：

      /‾\      /‾\
_____/   \____/   \__
```

更直接：

### 看 `atan2`

你的：

```c
theta =
-atan2(Ealpha, Ebeta);
```

如果：

```text
电机正转

theta：
0°
10°
20°
30°
40°
50°
...
```

连续增加，那么你的符号就是自洽的。

如果：

```text
0°
350°
340°
330°
...
```

那就是方向相反。

**这时候不是 PLL 的问题，而是 SMO 的 E 符号/电机方向定义问题。**

# 然后 PLL 就可以这样接

你现在这个 SMO 输出：

```c
smo->ebmf_alpha
smo->ebmf_beta
```

进入 PLL。

PLL：

```c
float Ealpha = smo->ebmf_alpha;
float Ebeta  = smo->ebmf_beta;

float theta = pll->theta_e;

float s = sinf(theta);
float c = cosf(theta);

/* Park */
float Ed =
    Ealpha * c +
    Ebeta  * s;

float Eq =
   -Ealpha * s +
    Ebeta  * c;

/* 反电动势幅值 */
float Emag =
    sqrtf(Ealpha * Ealpha +
          Ebeta  * Ebeta);

/* 防止低速/停止时除0 */
if (Emag > 0.1f)
{
    float error = -Ed / Emag;

    /* PLL PI */
    pll->integral +=
        pll->Ki * error * pll->Ts;

    pll->omega_e =
        pll->Kp * error +
        pll->integral;

    /* 积分得到电角度 */
    pll->theta_e +=
        pll->omega_e * pll->Ts;
}
```

这就是：

$$
\boxed{
E_{\alpha\beta}
\rightarrow
Ed
\rightarrow
PI
\rightarrow
\omega_e
\rightarrow
积分
\rightarrow
\theta_e
}
$$

# 还有一个我建议你马上改的地方

你现在：

```c
k_smo = 15.5f;
```

以及：

```c
SMO_Sat(error, 0.5f);
```

这两个参数其实是**强相关的**。

你的饱和函数：

$$
sat(e)=
\begin{cases}
1 & e>0.5\\
e/0.5 & |e|\le0.5\\
-1&e<-0.5
\end{cases}
$$

所以：

```text
电流误差 < 0.5A
```

的时候：

$$
Z=15.5\frac{e}{0.5}
$$

也就是：

$$
\boxed{Z=31e}
$$

而超过 0.5A 后：

$$
\boxed{Z=\pm15.5}
$$

所以你的 SMO 实际上是：

```text
          电流误差
              │
              ↓
         ±0.5A边界层
              │
              ↓
       Z = 15.5 × Sat()
              │
              ↓
       电流观测器反馈
```

这个才是你现在真正应该调的东西。

# 最后还有一个非常关键的工程问题

你现在的：

```c

```

必须和 **SMO 实际运行频率**完全一致。

如果：

```text

```

那么：

$$
\boxed{T_s=50\mu s}
$$

也就是：

```c
smo->Ts = 1.0f / 20000.0f;
```

如果 SMO 实际不是每个 FOC 周期执行一次，就不能这么写。
