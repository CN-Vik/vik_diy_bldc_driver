你这个需求：

> **AS5600 1kHz采样，实现几十RPM到几万RPM都准确测量**

先说结论：

**单纯“角度差 / 1ms”肯定做不到全速域准确。**

原因是低速和高速对测量方法的要求完全不同。

工程上一般采用：

> **低速：时间窗口法（位置差分）**
> **高速：周期/频率法（角度变化预测）**
> **中间：PLL融合**

对于FOC，推荐：

```
AS5600角度(1kHz)
        |
        |
   角度展开unwrap
        |
        |
   PLL速度估计器
        |
        |
  机械角速度 ωm
        |
        |
 RPM = ωm*60/360
```

# 1. 首先解决360°跳变

```c
        delta -= 360.0f;
    }
    else if(delta < -180.0f)
    {
        delta += 360.0f;
    }

}
```

# 3. 推荐方案：PLL速度估计（FOC标准方案）

这是TI C2000、VESC里面常见方法。

定义：

测量角：

$$
\theta_m
$$

估计角：

$$
\hat{\theta}
$$

速度：

$$
\hat{\omega}
$$

每1ms：

## 第一步预测

```c
theta_est += omega_est * dt;
```

---

## 第二步计算角度误差

注意角度也要wrap：

```c
error = angle_total - theta_est;
```

限制：

```
-180~180
```

---

## 第三步修正

类似PLL：

```c
theta_est += Kp * error;

omega_est += Ki * error;
```

代码：

```c
void pll_update(float angle)
{

    float error;


    error = angle - theta_est;


    // 角度误差限制
    if(error > 180)
        error -=360;

    if(error < -180)
        error +=360;



    theta_est += omega_est * dt
               + Kp * error;



    omega_est += Ki * error;


}
```

输出：

```
omega_est
```

就是机械角速度。

## 1. AS5600角度展开（unwrap）

先把0~360°变成连续角度。

例如：

```
350°
355°
2°
10°
```

变成：

```
350
355
362
370
```

代码：

```c
#include <math.h>


typedef struct
{
    float angle_last;      // 上一次AS5600角度
    float angle_total;     // 展开后的连续角度

} AngleUnwrap_t;



void angle_unwrap_init(AngleUnwrap_t *obj, float angle)
{
    obj->angle_last = angle;
    obj->angle_total = angle;
}



float angle_unwrap_update(AngleUnwrap_t *obj, float angle)
{
    float delta;


    delta = angle - obj->angle_last;


    // 跨越0度
    if(delta > 180.0f)
    {
        delta -= 360.0f;
    }

    else if(delta < -180.0f)
    {
        delta += 360.0f;
    }


    obj->angle_total += delta;


    obj->angle_last = angle;


    return obj->angle_total;
}
```

---

例如：

```c
float angle = AS5600_GetAngle();


float mechanical_angle;


mechanical_angle =
    angle_unwrap_update(&unwrap, angle);
```

现在：

```

2
5


输出:

```

# 2. PLL速度估计器

定义：

```c
typedef struct
{

    float theta;       // 估计角度

    float omega;       // 估计角速度 deg/s


    float kp;

    float ki;


    float dt;


} PLL_t;
```

---

初始化：

你的采样：

1kHz

所以：

```c
dt=0.001


void pll_init(PLL_t *pll)
{

    pll->theta = 0;

    pll->omega = 0;


    pll->kp = 80.0f;

    pll->ki = 2000.0f;


    pll->dt = 0.001f;

}
```

---

更新函数：

```c
float limit_angle_error(float error)
{

    while(error > 180)
        error -= 360;


    while(error < -180)
        error += 360;


    return error;
}




void pll_update(PLL_t *pll,
                float angle_measure)
{


    float error;



    // 角度误差
    error =
        angle_measure - pll->theta;



    // 限制到±180
    error =
        limit_angle_error(error);



    // PLL
    pll->theta += 
        pll->omega * pll->dt
        +
        pll->kp * error * pll->dt;



    pll->omega +=
        pll->ki * error * pll->dt;



}
```
