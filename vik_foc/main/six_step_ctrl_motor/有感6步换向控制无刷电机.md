as5600.c

```c
#define AS5600_ADDR 0x36


#define AS5600_ANGLE_MSB 0x0E
#define AS5600_ANGLE_LSB 0x0F



uint16_t as5600_read_raw_angle(void)
{
    uint8_t data[2];


    i2c_master_write_read_device(
        I2C_NUM_0,
        AS5600_ADDR,
        &reg,
        1,
        data,
        2,
        100
    );


    uint16_t raw;


    raw = ((data[0]&0x0F)<<8)
          |
          data[1];


    return raw;
}
```

---

转换：

```c
float as5600_get_angle_deg(void)
{

    uint16_t raw;


    raw = as5600_read_raw_angle();


    return raw * 360.0f / 4096.0f;

}
```

结果：

```
0~359.91°
```

你现在做的是 **AS5600 有感六步换相（方波控制 / BLDC trapezoidal control）**，这个跟你之前搞的 FOC 完全是两套东西。

AS5600 本质是**绝对角度传感器**，不是霍尔，所以不能直接像传统 BLDC 那样输出 6 个霍尔状态。你需要：

> AS5600角度 → 判断电角度 → 查表得到六步换相状态 → 输出三相PWM

AS5600 可以通过 I2C 读角度，也可以配置 OUT 输出 PWM，占空比对应角度。

# 5. 六步换相表

比如正转：

| 扇区 | A相  | B相  | C相  |
| -- | --- | --- | --- |
| 0  | PWM | OFF | LOW |
| 1  | PWM | LOW | OFF |
| 2  | OFF | LOW | PWM |
| 3  | LOW | OFF | PWM |
| 4  | LOW | PWM | OFF |
| 5  | OFF | PWM | LOW |

代码：

```c
typedef enum
{
    PHASE_OFF=0,
    PHASE_PWM,
    PHASE_LOW

}phase_state_t;


typedef struct
{

    phase_state_t A;
    phase_state_t B;
    phase_state_t C;

}comm_table_t;



const comm_table_t comm_table[6]=
{

    {PHASE_PWM, PHASE_OFF, PHASE_LOW},

    {PHASE_PWM, PHASE_LOW, PHASE_OFF},

    {PHASE_OFF, PHASE_LOW, PHASE_PWM},

    {PHASE_LOW, PHASE_OFF, PHASE_PWM},

    {PHASE_LOW, PHASE_PWM, PHASE_OFF},

    {PHASE_OFF, PHASE_PWM, PHASE_LOW},

};
```

# 6. 换相函数

motor_6step.c

```c
void motor_commutation(float angle)
{

    float elec_angle;


    elec_angle = angle * POLE_PAIRS;


    while(elec_angle>=360)
        elec_angle-=360;


    uint8_t sector;

    sector = elec_angle / 60;


    apply_phase(
        comm_table[sector]
    );

}
```

# 9. AS5600采样频率问题

```

```

```

```


不像FOC需要连续电角度。

不过提醒你一个关键点：

**AS5600做六步比霍尔高级，但低速启动需要特殊处理。**

因为启动时：

```
转子不知道位置
```

你必须：

1. 定位：

```
固定A/B相
等待100ms
```

让转子吸到一个位置

2. 开始六步

3. 等速度起来后闭环

否则静止直接：

```
读AS5600
→ 六步
```

可能抖动。

你这个电机有7对极，用AS5600做六步其实比霍尔还精确，后面甚至可以直接升级成 **有感FOC**。你现在的FOC框架基本可以复用，只是把SVPWM换成六步换相。
