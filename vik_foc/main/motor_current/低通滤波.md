你这个函数最大的几个问题：

1. **只能滤波一个变量**（用了 static，全局共享状态）

   * 你滤完电流，再去滤速度，状态就乱了。
   * FOC 里面绝对不能这样。

2. **不是线程安全**

   * FreeRTOS 多个 task 调用会互相影响。

3. **不能复位**

   * 编码器掉线、重新校准后，没办法清空滤波器。

4. **多个电流(A/B/C)、角度、速度都需要各自保存历史值。**

---

## 推荐行业写法（结构体版）

```c
#ifndef LOW_PASS_FILTER_H
#define LOW_PASS_FILTER_H

#include <stdbool.h>

typedef struct
{
    float output;      /* 上一次输出 */
    float alpha;       /* 滤波系数 */
    bool  inited;      /* 是否初始化 */
} low_pass_filter_t;

/**
 * @brief 初始化
 */
static inline void low_pass_filter_init(low_pass_filter_t *filter,
                                        float alpha)
{
    if(alpha < 0.0f)
        alpha = 0.0f;
    else if(alpha > 1.0f)
        alpha = 1.0f;

    filter->alpha = alpha;
    filter->output = 0.0f;
    filter->inited = false;
}

/**
 * @brief 修改滤波系数
 */
static inline void low_pass_filter_set_alpha(low_pass_filter_t *filter,
                                             float alpha)
{
    if(alpha < 0.0f)
        alpha = 0.0f;
    else if(alpha > 1.0f)
        alpha = 1.0f;

    filter->alpha = alpha;
}

/**
 * @brief 清除历史
 */
static inline void low_pass_filter_reset(low_pass_filter_t *filter,
                                         float value)
{
    filter->output = value;
    filter->inited = true;
}

/**
 * @brief 一阶低通滤波
 */
static inline float low_pass_filter(low_pass_filter_t *filter,
                                    float input)
{
    if(!filter->inited)
    {
        filter->output = input;
        filter->inited = true;
        return input;
    }

    filter->output +=
        filter->alpha * (input - filter->output);

    return filter->output;
}

#endif
```

---

## 使用方式

例如你的FOC：

```c
low_pass_filter_t ia_filter;
low_pass_filter_t ib_filter;
low_pass_filter_t speed_filter;
low_pass_filter_t angle_filter;
low_pass_filter_t torque_filter;
```

初始化

```c
low_pass_filter_init(&ia_filter, 0.10f);
low_pass_filter_init(&ib_filter, 0.10f);
low_pass_filter_init(&speed_filter, 0.15f);
low_pass_filter_init(&angle_filter, 0.08f);
low_pass_filter_init(&torque_filter, 0.10f);
```

滤波

```c
ia = low_pass_filter(&ia_filter, ia_adc);

ib = low_pass_filter(&ib_filter, ib_adc);

speed = low_pass_filter(&speed_filter, speed);

angle = low_pass_filter(&angle_filter, angle);

torque = low_pass_filter(&torque_filter, torque);
```

这样每个变量互不影响。

## 如果用于FOC，我还建议增加一个 Ts 自动计算 alpha

目前你的 alpha 都是手动填：

```c
alpha = 0.1;
```

实际上行业里更多采用截止频率来配置，而不是直接写 alpha。

根据采样周期自动计算：

```text
alpha = Ts / (RC + Ts)

RC = 1 / (2πFc)
```

例如

```c
void low_pass_filter_init(low_pass_filter_t *filter,
                          float sample_time,
                          float cutoff_freq)
{
    float rc;

    rc = 1.0f / (2.0f * 3.1415926f * cutoff_freq);

    filter->alpha = sample_time / (sample_time + rc);

    filter->output = 0.0f;
    filter->inited = false;
}
```

例如：

FOC 电流环 **10 kHz**

```c
Ts = 0.0001f;
```

截止频率

```c
Fc = 500Hz
```

得到

```text
alpha ≈ 0.239
```

如果

```text
Fc = 100Hz
```

则

```text
alpha ≈ 0.059
```

这样无论你的控制频率以后改成 **20 kHz、30 kHz、40 kHz**，滤波特性都会保持一致，而不用重新去调 `alpha`。

---

**对于你现在做的猫砂盆 FOC 项目，我建议统一采用这种结构体版，并使用“采样周期 + 截止频率”初始化方式，而不是直接写 `alpha`。** 这是电机控制、FOC 和工业控制中更常见、更容易维护的实现方式，也方便以后统一管理电流、速度、角度等多个滤波器。
