有，而且区别非常明显。你的电流采样已经能区分“电机转动”和“电机静止”。

## 对比结果

| 状态 |       M0 相电流 RMS |              峰值范围 | 结论       |
| -- | ---------------: | ----------------: | -------- |
| 静止 | 约 `0.003～0.005A` | 大约 `-0.03～+0.03A` | 基本是ADC噪声 |
| 转动 |   约 `0.10～0.37A` | 大约 `-0.45～+0.55A` | 存在明显相电流  |

例如转动时：

```text
M0_CS2: rms=0.302A, min=-0.452A, max=0.302A
M0_CS1: rms=0.367A, min=0.004A,  max=0.534A
```

静止时：

```text
M0_CS2: rms=0.004A, min=-0.026A, max=0.012A
M0_CS1: rms=0.003A, min=-0.006A, max=0.012A
```

电机转动时的 RMS 电流比静止噪声大了几十倍，说明：

```text
INA240输出正常
ADC通道映射基本正确
M0电流采样能够检测到电机相电流
```

而 M1 始终保持：

```text
rms ≈ 0.004A
```

也符合 M1 电机没有运行的情况。

## 重点看哪些数据

判断有没有电流，主要看：

```text
rms
abs_avg
min
max
```

不要主要看：

```text
avg
instant
```

因为三相电机相电流是正负交变的：

```text
+0.3A → 0A → -0.3A → 0A
```

所以：

```text
avg ≈ 0A
```

并不代表没有电流。

你这里转动状态下：

```text
abs_avg = 0.08～0.35A
rms     = 0.10～0.37A
```

静止状态：

```text
abs_avg = 0.003～0.004A
rms     = 0.003～0.005A
```

区别已经非常清楚。

## 可以设置一个简单的电流存在阈值

根据你目前的静止噪声，可以暂时这样判断：

```c
#define MOTOR_CURRENT_ACTIVE_THRESHOLD_A  0.05f

bool current_is_active =
    current_rms > MOTOR_CURRENT_ACTIVE_THRESHOLD_A;
```

大致判断：

```text
RMS < 0.02A   基本无电流
RMS > 0.05A   明显有电流
RMS > 0.10A   电机正在实际输出
```

这个阈值后面可以根据实际负载再调整。

## 但你的日志还有一个需要注意的问题

静止时日志显示：

```text
uq = -3.20
目标速度 = 89
当前速度 = 0
误差 = 89
```

可是相电流仍然只有：

```text
3～5mA
```

这在物理上有点不正常。

如果：

```text
Uq确实为-3.2V
MOS驱动已经使能
母线电源正常
PWM确实输出到三相桥
```

那么即使电机不转，绕组中通常也应该存在明显电流，而不是只有几毫安。

所以这里有两种可能。

### 情况一：这个 Uq 只是计算出来了，实际没有输出

比如：

```text
Uq计算为-3.2
但FD6287没有使能
或者MCPWM没有真正启动
或者MOS母线没有供电
```

这种情况下打印有 Uq，但实际电机没有电流。

### 情况二：静止日志是在驱动关闭状态下采集的

如果你故意关闭了 MOS 或 PWM，只是保留了速度环的日志，那么静止时 `0A` 是正常的。

你可以直接做一个验证：

```text
让电机处于静止
使能三相桥
固定电角度
给一个很小的Uq，例如0.3V
```

正常情况下应该看到：

```text
M0_CS1或M0_CS2的RMS明显高于0.05A
```

然后逐渐增加：

```text
Uq = 0.3V
Uq = 0.5V
Uq = 1.0V
```

观察相电流是否随 Uq 增大。

不要一开始就在静止状态给 `3.2V`，因为堵转时没有反电动势，电流可能快速增大。

## 转动时速度数据也有异常迹象

日志里目标速度是：

```text
89 RPM
```

但测量速度出现：

```text
745 RPM
783 RPM
859 RPM
887 RPM
```

然后 Uq 在：

```text
+3.20V
-3.06V
+3.20V
-2.95V
```

之间翻转。

这说明速度环目前可能存在：

```text
速度测量跳变
速度滤波不足
PID参数过大
速度方向符号错误
角度跨0°处理问题
```

相电流采样本身看起来是有效的，但速度环明显还没有稳定。

## 最终结论

你的两组数据区别很大：

```text
静止：约3～5mA，属于噪声底
转动：约0.1～0.37A RMS，确实存在相电流
```

所以 INA240A2 和 ADC 读取已经基本成功。接下来需要重点确认：为什么静止时日志显示 `Uq=-3.2V`，实际相电流却接近零；如果此时驱动桥确实使能，那说明 Uq 没有真正作用到三相 PWM 输出。
