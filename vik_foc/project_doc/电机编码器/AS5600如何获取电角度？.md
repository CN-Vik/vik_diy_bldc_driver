# AS5600 + FOC 电角度 一步到位计算方法
我直接给你**最实用、能直接写进代码**的公式和步骤，这是无刷电机FOC控制的核心！

---

## 一、先记住一句话
**电角度 = 机械角度 × 极对数 / 360° 取模**

AS5600 输出的是**机械角度**，
FOC 需要的是**电角度**。

---

## 二、关键定义
1. **AS5600 原始值**：`rawAngle`（0 ~ 4095）
2. **机械角度**：`mechAngle = rawAngle * 360.0f / 4096.0f`
3. **极对数 P** = 电机**磁铁极数 ÷ 2**
   - 12N14P → P=7
   - 12N10P → P=5
   - 云台电机大多 P=11 或 P=14
4. **电角度**：FOC 用这个！

---

## 三、最终公式（直接复制用）
```cpp
// 1. 读取AS5600原始值
uint16_t raw = as5600_getRawAngle(); 

// 2. 转成机械角度 0~360°
float mech = raw * 360.0f / 4096.0f;

// 3. 计算电角度（核心！）
float elec = mech * POLE_PAIRS;  // POLE_PAIRS = 极对数

// 4. 限制在 0~360° 范围
elec = fmodf(elec, 360.0f);
if(elec < 0) elec += 360.0f;
```

**这就是 FOC 算法需要的电角度！**

---

## 四、最重要一步：校正偏移（电角度校准）
AS5600 上电默认角度 ≠ 电机真正的电角度
必须**校正一次**，否则 FOC 力矩不对、电机抖动！

### 校准方法（简单暴力）
1. 手动转动电机，找到**最大力矩位置**
2. 记录此时的 `elec`
3. 以后每次计算都加上这个偏移量：

```cpp
float elec = (mech * POLE_PAIRS) + ANGLE_OFFSET;
elec = fmodf(elec, 360.0f);
```

`ANGLE_OFFSET` 就是你的校准值（一般在 -180 ~ +180 之间）

## 六、你只需要记住3步
1. **AS5600 → 机械角度**
2. **×极对数 → 电角度**
3. **加偏移校准 → 给FOC用**

---

### 总结
- **电角度 = 机械角度 × 极对数**
- AS5600 给的是机械角度
- 必须校准偏移，否则 FOC 不转/抖动/发热
