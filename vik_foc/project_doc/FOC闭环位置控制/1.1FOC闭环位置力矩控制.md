# 一、一句话核心结论（必须背下来）
### **位置环 → 速度环 → 最终输出 Iq = 力矩大小**
- **Iq 越大 → 力矩越大**
- **Iq 越小 → 力矩越小**
- **Iq=0 → 电机无力矩（自由旋转）**

你要控制力矩，**只需要控制 Iq 的上限！**

# 三、那怎么限制/控制力矩？
## 方法超级简单：
### **给 Iq 加一个上限（限幅）**
这就是**力矩限制**！

例如：
```cpp
// 你想让电机最大力矩不超过 0.8A
#define MAX_IQ  0.8f  

// 速度环计算出 Iq 后，必须加这一行！
if(Iq >  MAX_IQ) Iq =  MAX_IQ;
if(Iq < -MAX_IQ) Iq = -MAX_IQ;
```

### 这个 MAX_IQ 就是：
- 最大力矩
- 最大力气
- 最大电流

你改这个值，**力矩立刻变大/变小**。

# 四、位置闭环里力矩控制的完整逻辑
```
1. 目标角度 - 当前角度 = 角度误差
2. 角度误差 × KP = 目标速度
3. 目标速度 - 当前速度 = 速度误差
4. 速度PID = Iq（力矩）
5. Iq 限幅 = 限制最大力矩
6. 送入FOC → 电机出力
```

## 重点：
**位置环不直接出力矩！
速度环输出 Iq，才是真正的力矩！**

# 五、最实用代码（直接复制进你的FOC）
```cpp
// 1. 位置环（P）
float err = target_angle - now_angle;
err = normalizeAngle(err);  // 误差限制在 -180~180
float target_speed = err * KP_POS;  

// 2. 速度限幅（防止速度太快）
limit(target_speed, -MAX_SPEED, MAX_SPEED);

// 3. 速度环（PI）
float speed_err = target_speed - now_speed;
float Iq = KP_VEL * speed_err + (KI_VEL * integral_speed);

// ==========================
//  👇 这里就是力矩控制！👇
// ==========================
#define MAX_IQ  0.6f   // 0.6A 力矩，改这里就行！
limit(Iq, -MAX_IQ, MAX_IQ);  

// 4. FOC 输出
FOC_set(0, Iq, elec_angle);
```
