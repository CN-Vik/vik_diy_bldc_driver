开环 FOC + SPWM 速度控制，本质上是：

**不给电机速度/位置反馈，直接让定子磁场按你设定的速度旋转，电机转子“跟着跑”。**

它不是严格意义上的“速度闭环控制”，而是**速度给定型开环驱动**。

---

# 1. 开环 FOC + SPWM 的核心原理

FOC 的目标是控制一个旋转磁场。

对于永磁同步电机 / BLDC 来说，可以简单理解为：

**转子有一个永磁磁场，定子三相绕组产生一个旋转磁场。**

开环 FOC 就是人为生成一个旋转电压矢量：

```c
Ud = 0;
Uq = 固定电压;
theta_e += omega_e * dt;
```

然后通过反 Park、反 Clarke，把这个旋转电压矢量变成三相电压：

```c
Ualpha / Ubeta  ->  Ua / Ub / Uc
```

最后用 SPWM 输出三相正弦 PWM：

```c
Ua -> PWM_A
Ub -> PWM_B
Uc -> PWM_C
```

---

# 2. 整体控制流程

完整流程如下：

```text
目标机械转速 RPM
        ↓
机械角速度 ωm
        ↓
电角速度 ωe = 极对数 × 机械角速度
        ↓
积分得到电角度 theta_e
        ↓
给定 Ud = 0, Uq = 某个电压
        ↓
反 Park 变换
        ↓
反 Clarke 变换
        ↓
得到三相正弦电压 Ua Ub Uc
        ↓
SPWM 生成三相 PWM
        ↓
三相逆变器驱动 BLDC / PMSM
```

核心公式是：

```c
omega_m = target_rpm * 2.0f * PI / 60.0f;
omega_e = pole_pairs * omega_m;
theta_e += omega_e * dt_s;
```

其中：

```c
target_rpm   // 目标机械转速，单位 r/min
omega_m      // 机械角速度，单位 rad/s
omega_e      // 电角速度，单位 rad/s
pole_pairs   // 极对数
theta_e      // 电角度
dt_s         // 控制周期，单位秒
```

---

# 3. Uq 是什么？

在开环 FOC 里，一般这样设：

```c
Ud = 0;
Uq = 目标电压;
```

可以简单理解为：

```text
Uq 越大，电机驱动力越强
Uq 太小，电机带不动，容易失步
Uq 太大，电机发热、电流大、啸叫明显
```

注意，这里的 `Uq` 通常单位就是 **V**。

比如你现在 12V 电源，可以先测试：

```c
Uq = 1.0V ~ 3.0V   // 小电机空载学习阶段
Uq = 3.0V ~ 5.0V   // 扭矩更强，但要注意电流和发热
```

不建议一开始给太大。

---

# 4. SPWM 是怎么输出的？

SPWM 的意思是：

**用 PWM 的占空比模拟正弦电压。**

比如三相电压是：

```c
Ua = sin(theta);
Ub = sin(theta - 120°);
Uc = sin(theta + 120°);
```

然后把它们转换成 PWM 占空比：

```c
duty_a = 0.5f + Ua / Vbus;
duty_b = 0.5f + Ub / Vbus;
duty_c = 0.5f + Uc / Vbus;
```

实际代码里会做限幅：

```c
if (duty_a > 1.0f) duty_a = 1.0f;
if (duty_a < 0.0f) duty_a = 0.0f;
```

最终 MCU 输出三路 PWM，驱动三相桥。

---

# 5. 开环 FOC + SPWM 控制的本质

它的本质不是：

```text
我检测到电机速度慢了，所以加大输出
```

而是：

```text
我假设电机一定跟得上我设定的电角度
```

所以开环 FOC 最大的问题就是：

**它不知道转子真实位置。**

比如你给：

```c
target_rpm = 1000;
```

程序会让电角度按照 1000RPM 对应的速度旋转。

但是电机是否真的达到 1000RPM？

开环控制并不知道。

---

# 6. 为什么开环 FOC 能让电机转起来？

因为低速、空载、轻载时，转子磁场会被定子旋转磁场“拖着走”。

类似这样：

```text
定子磁场在前面转
转子磁场在后面追
```

只要：

```text
旋转速度不太快
负载不太重
Uq 电压足够
加速过程不突变
```

电机就能跟上。

一旦跟不上，就会：

```text
失步
抖动
啸叫
卡住
发热
电流变大
```

---

# 7. 开环 FOC + SPWM 的优点

## 优点 1：代码简单

不需要：

```text
编码器
霍尔传感器
电流采样
速度环 PID
电流环 PID
位置观测器
反电动势估算
```

只需要：

```text
目标速度
电角度积分
Uq
SPWM
```

非常适合新手学习 FOC。

---

## 优点 2：容易理解 FOC 坐标变换

开环 FOC 很适合学习这些东西：

```text
电角度 theta_e
Park 逆变换
Clarke 逆变换
三相正弦 PWM
SPWM / SVPWM
极对数
机械角度和电角度关系
```

你现在这个阶段，用它打基础非常合适。

---

## 优点 3：不依赖传感器

没有编码器、霍尔、电流采样也能让电机转起来。

所以它适合：

```text
FOC 入门实验
电机硬件初步验证
三相桥驱动验证
PWM 波形验证
电机空载旋转测试
```

---

## 优点 4：低速空载效果还可以

如果电机空载，速度不高，Uq 合理，开环 FOC 可以比较平滑地转起来。

相比六步换向，它的电流和转矩波动通常更小。

---

# 8. 开环 FOC + SPWM 的缺点

## 缺点 1：没有真正速度控制能力

你设定的是：

```c
target_rpm = 1000;
```

但实际电机可能是：

```text
800 RPM
950 RPM
失步
卡住
```

因为它没有速度反馈。

所以严格来说，它不是高性能速度控制，而是：

```text
按给定频率旋转磁场
```

---

## 缺点 2：负载能力差

负载一变，电机可能跟不上。

比如电机空载可以转，但是一加负载就：

```text
转速下降
抖动
啸叫
停转
```

因为程序不知道负载变大了，也不会自动补偿。

---

## 缺点 3：启动不可靠

开环启动时，转子实际位置未知。

你程序里的 `theta_e = 0`，但真实转子不一定在这个位置。

所以启动时可能：

```text
先抖一下
反向抖动
啸叫
启动失败
```

一般需要先做一个**预定位**：

```c
theta_e = 固定角度;
Uq = 小电压;
保持 200ms ~ 1000ms;
```

让转子先被拉到一个已知位置，然后再慢慢加速。

---

## 缺点 4：效率不高

真正的 FOC 会让电流矢量和转子磁场保持合适角度。

但开环 FOC 不知道转子真实位置，所以磁场角度可能不准。

结果就是：

```text
一部分电流没有产生有效转矩
电机发热
效率下降
噪声增加
```

---

## 缺点 5：高速容易失步

速度越高，对角度准确性要求越高。

开环时如果加速太快，转子追不上定子磁场，就会失步。

所以必须做缓启动：

```c
current_rpm += ramp_step;
```

不能直接从：

```c
0 RPM -> 3000 RPM
```

应该慢慢升上去。

---

## 缺点 6：SPWM 电压利用率低于 SVPWM

SPWM 简单，但是母线电压利用率不如 SVPWM。

也就是说，同样 12V 电源：

```text
SPWM 能输出的最大有效相电压较低
SVPWM 能更充分利用直流母线电压
```

所以量产高性能电机控制里，通常更常用：

```text
FOC + SVPWM + 电流环 + 速度环 + 位置/无感估算
```

而不是开环 FOC + SPWM。

---

# 9. 适合应用在哪里？

开环 FOC + SPWM 适合：

```text
FOC 入门学习
BLDC 空载测试
三相驱动板验证
PWM 波形验证
电机能否转动测试
低成本小功率风扇类应用
简单演示 Demo
```

比如你现在用 ESP32 学 FOC，这个非常适合第一步。

---

# 10. 不适合应用在哪里？

不适合：

```text
平衡车
电动车
云台
机器人关节
伺服电机
带负载精确调速
高效率产品
高速大功率电机
需要快速动态响应的系统
```

比如你后面想做平衡车，这种开环 FOC 肯定不够。

平衡车至少需要：

```text
电流环
速度环
姿态环
编码器 / 霍尔 / 无感估算
IMU
PID 或其他控制算法
```

# 11. 开环 FOC + SPWM 和真正闭环 FOC 的区别

| 项目        | 开环 FOC + SPWM | 闭环 FOC |
| --------- | ------------- | ------ |
| 是否知道转子位置  | 不知道           | 知道或估算  |
| 是否知道实际速度  | 不知道           | 知道     |
| 是否有电流环    | 通常没有          | 有      |
| 是否能抗负载变化  | 差             | 好      |
| 启动可靠性     | 一般            | 高      |
| 效率        | 一般            | 高      |
| 控制难度      | 简单            | 难      |
| 适合学习      | 非常适合          | 进阶     |
| 适合量产高性能产品 | 不适合           | 适合     |

# 12. 最小代码逻辑大概长这样

```c
void foc_open_loop_spwm_update(float target_rpm, float uq, float dt_s)
{
    float omega_m;
    float omega_e;

    float ud = 0.0f;

    float u_alpha;
    float u_beta;

    float ua;
    float ub;
    float uc;

    float duty_a;
    float duty_b;
    float duty_c;

    /*
     * 1. 机械转速 RPM 转机械角速度 rad/s
     */
    omega_m = target_rpm * FOC_2PI / 60.0f;

    /*
     * 2. 机械角速度转电角速度
     */
    omega_e = omega_m * motor_pole_pairs;

    /*
     * 3. 积分得到电角度
     */
    theta_e += omega_e * dt_s;

    /*
     * 4. 电角度归一化到 0 ~ 2π
     */
    if (theta_e >= FOC_2PI)
    {
        theta_e -= FOC_2PI;
    }
    else if (theta_e < 0.0f)
    {
        theta_e += FOC_2PI;
    }

    /*
     * 5. 反 Park 变换
     * Ud = 0
     * Uq = 给定电压
     */
    u_alpha = ud * cosf(theta_e) - uq * sinf(theta_e);
    u_beta  = ud * sinf(theta_e) + uq * cosf(theta_e);

    /*
     * 6. 反 Clarke 变换
     */
    ua = u_alpha;
    ub = -0.5f * u_alpha + 0.8660254f * u_beta;
    uc = -0.5f * u_alpha - 0.8660254f * u_beta;

    /*
     * 7. 三相电压转 PWM 占空比
     * 这里假设 ua/ub/uc 的范围大概是 -Vbus/2 ~ +Vbus/2
     */
    duty_a = 0.5f + ua / vbus;
    duty_b = 0.5f + ub / vbus;
    duty_c = 0.5f + uc / vbus;

    /*
     * 8. 占空比限幅
     */
    duty_a = foc_constrain(duty_a, 0.0f, 1.0f);
    duty_b = foc_constrain(duty_b, 0.0f, 1.0f);
    duty_c = foc_constrain(duty_c, 0.0f, 1.0f);

    /*
     * 9. 设置三相 PWM
     */
    motor_set_pwm_duty(duty_a, duty_b, duty_c);
}
```

# 13. 实际调试建议

你现在学习阶段可以这样做：

```c
PWM_FREQ = 20kHz ~ 30kHz
控制周期 = 50us ~ 100us
Uq = 1.0V 起步
RPM = 100 起步
```

然后慢慢加：

```c
Uq: 1V -> 2V -> 3V
RPM: 100 -> 300 -> 500 -> 1000
```

不要一开始就：

```c
Uq = 5V
RPM = 3000
```

否则很容易：

```text
尖叫
抖动
失步
电机发热
驱动 MOS 发热
```

---

# 14. 一句话总结

**开环 FOC + SPWM 速度控制，就是用软件生成一个按目标速度旋转的电压矢量，再用三相正弦 PWM 输出，让电机转子尽量跟着这个旋转磁场走。**

它非常适合学习 FOC 原理和验证硬件，但不适合高性能、带负载、精准速度控制的产品。
你后面真正要做高性能电机控制，最终方向应该是：

```text
FOC + SVPWM + 电流采样 + 电流环 + 速度环 + 位置反馈/无感观测
```
